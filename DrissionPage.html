03 第一个程序

目标：打开一个网页，往搜索框里打字，点按钮，把页面标题打印出来。全程不到 10 行。

1 新建文件 first.py

在刚才的 dp-lab 文件夹里新建 first.py，把下面整段复制进去。绿色注释是解释，可以不抄。

first.py写进文件后用 python first.py 运行
from DrissionPage import Chromium
# from = 从 DrissionPage 这个库里；import = 导入；Chromium = 浏览器对象（5.0 唯一入口）

browser = Chromium()
# Chromium() = 启动或接管一个浏览器；= 把结果存进变量 browser

tab = browser.latest_tab
# latest_tab = 最后激活的那个标签页；tab 后面所有操作都靠它

tab.get('https://www.baidu.com')
# get = 访问网址；5.0 返回一个 NavResult 对象，第 7 章讲怎么读

tab.ele('#kw').input('DrissionPage')
# ele = element 找一个元素；'#kw' = id 为 kw 的元素（搜索框）
# input = 输入文本；这里是往搜索框写 DrissionPage

tab('#su').click()
# tab('#su') 是 tab.ele('#su') 的简写；click = 点击（百度一下按钮）

print(tab.title)
# print = 打印到终端；title = 当前网页标题

终端（确保已经 cd 进 dp-lab）只敲 $ 行

10.3 静态副本加速（读大量数据时必用）

为什么能快十几倍

动态元素（ele() 结果）每读一次属性都要和浏览器通信一次。静态副本（s_ele() / s_eles()）是把 HTML 拷一份到本地解析，之后读文字、属性全在内存里完成。官方实测：打印 1613 个链接从 4.06 秒降到 0.28 秒。

fast.py写进文件
from DrissionPage import Chromium

tab = Chromium().latest_tab
tab.get('https://gitee.com/explore/all')

body = tab.ele('t:body')       # 只跟浏览器要一次最外层容器
links = body.s_eles('t:a')      # s_eles = 转成本地静态副本列表，之后不再通信
for a in links[:10]:          # [:10] = 只看前 10 个
    print(a.text, a.link)
静态副本的边界

它是纯文本快照：不能点击、不能输入，也不影响原来的动态元素。一页只转一次最高级容器即可；反复调 s_ele() 反而更慢。要交互还是得用 ele()。

检查点

① 能用 parent() / next() 从锚点找邻居。
② 能用 filter.displayed() 过滤列表。
③ 知道「只读大量数据用 s_eles，要点击用 ele」。

11 iframe、ShadowRoot 与跨域

网页里套网页、组件里藏组件，是新手最容易「明明有元素却找不到」的原因。5.0 还专门增强了跨域能力。

11.1 iframe 的两种取法

iframe.py写进文件
from DrissionPage import Chromium

tab = Chromium().latest_tab
tab.get('https://drissionpage.cn/demos/iframe_diff_domain.html')

iframe = tab.get_frame('t:iframe')
# get_frame = 取框架对象；'t:iframe' = 按标签名找 iframe
ele = iframe.ele('新闻')       # 在这个框架内部找元素（旧写法）
print(ele.text)

ele2 = tab.ele('新闻')         # 仅 5.0：跨域也能直接从 tab 找
print(ele2.text)
方法作用
tab.get_frame(loc)取一个 iframe，返回 ChromiumFrame（既能当元素，又能当页面）
tab.get_frames(loc)取所有符合条件的 iframe（较慢，少用）
iframe.ele() / iframe.get()在框架内找元素 / 让框架自己跳网址
tab.ele()（5.0）同域任意层直接找；跨域在满足条件时也能直接找
5.0 跨域能力的两个前提

① 必须用 DrissionPage 启动的浏览器，或手动加了 --disable-site-isolation-trials 启动参数的浏览器。
② 如果发现异常，可用 ChromiumOptions().close_cross_origin() 关掉这个增强功能，退回旧写法。

11.2 ShadowRoot（影子 DOM）

一些现代组件把内容藏在 Shadow DOM 里，普通定位符进不去。取它的根节点用 shadow_root，简写 sr。

shadow.py写进文件
root = tab.ele('#history-app').sr
# sr = shadow_root 的简写；注意是「属性」，后面不加括号
items = root.eles('t:history-item')   # 在影子根里找元素
for it in items:
    print(it.text)
嵌套 ShadowRoot 不能跳级

要一层一层取：先拿外层元素的 .sr，在里面找到下一层元素，再取它的 .sr。不要指望一次定位符跨两级。

检查点

① 知道「主页面里找不到」时先想是不是在 iframe 里。
② 会写 tab.get_frame('t:iframe')。
③ 知道 .sr 不加括号、且不能跨级。

16 上传文件

上传的本质是「把文件路径交给网页的文件选择框」。三种写法，按页面情况选。

upload.py写进文件
from DrissionPage import Chromium

tab = Chromium().latest_tab
tab.get('https://example.com/upload')

# 写法一（最省事）：点击按钮时直接把路径塞进去
tab.ele('#uploadButton').click.to_upload(r'C:\test.txt')
# click.to_upload = 点击并自动处理文件选择框；r'' 保护 Windows 反斜杠

# 写法二（按钮不好点时）：先预设路径，再点，再等它填完
tab.set.upload_files(r'C:\test.txt')   # 预设要上传的文件
tab.ele('@text()=选择文件').click()      # 触发文件选择框
tab.wait.upload_paths_inputted()               # 等路径填完；5.0 新增 timeout 参数

# 写法三（页面上就有 input 元素）：直接往 input 里写路径
tab.ele('tag:input@type=file').input(r'D:\a.txt')
# 多个文件可传列表 ['a.txt','b.txt']，或用 \n 分隔的字符串
写法什么时候用
click.to_upload(paths)最常用，一键完成
set.upload_files() + click() + wait.upload_paths_inputted()按钮是异步触发、或需要精细控制时
input(path) 写进 input[type=file]页面直接暴露文件输入框时
Windows 路径与两个坑

① 路径一律写成 r'C:\test.txt'（前缀 r = raw，原始字符串），否则 \t 会被当成制表符，路径就错了。
② 异步上传必须等 wait.upload_paths_inputted()，不然代码跑完了文件还没填进去。
③ 文件在跨域 iframe 里时，要用那个 iframe 对象的 set.upload_paths()，不能用外层 tab。

检查点

能用写法一完成一次上传，并知道 Windows 路径为什么要加 r。

tab = browser.latest_tab                   # 取标签页

res = tab.get('https://gitee.com/login')   # 访问登录页

tab.ele('#user_login').input('你的账号')
# #user_login = 按 id 找账号框；input = 输入
tab.ele('#user_password').input('你的密码')
tab.ele('@value=登 录').click()         # @value= = 按 value 属性找按钮；click = 点击

tab.wait.url_change('login', exclude=True)
# 等网址不再是 login 页；exclude=True = 「不包含 login」才算成功
print('登录后网址：', tab.url)

tab.change_mode()                         # 切到 s 模式，带着 cookies 高速翻页

lines = []
# lines = 空列表，用来攒结果；[] 造一个空列表
for i in range(1, 4):                  # range(1,4) = 1、2、3
    tab.get(f'https://gitee.com/explore/all?page={i}')

    titles = tab.eles('t:h3').get.texts()

    for t in titles:
        lines.append(f'{i}\t{t}')     # append = 往列表末尾加一项；\t = 制表符
    print(f'第 {i} 页拿到 {len(titles)} 条')  # len() = 列表长度

with open('result.txt', 'w', encoding='utf-8') as f:
    # with open = 打开文件并自动关闭；'w' = 写入；encoding = 编码
    f.write('\n'.join(lines))         # '\n'.join = 用换行把列表拼成一大段文字

print('已保存 result.txt，共', len(lines), '条')
browser.quit()                            # 收尾：关浏览器

手上有一个字符串，能唯一认出那个接口请求。

2 写脚本
listen_download.py写进文件
from DrissionPage import Chromium, SessionPage

KEY = 'api/getlist'        # KEY = 常量：接口网址里独有的那一段；大写表示「不要改」

browser = Chromium()
tab = browser.latest_tab
tab.listen.set_method.GET(only=True)  # 仅 5.0：只听 GET 请求
tab.listen.start(KEY)                    # ① 先开监听
tab.get('https://example.com/list')  # ② 再访问，触发请求

urls = []                               # 空列表，攒文件网址
for packet in tab.listen.steps(count=5):
    # steps = 一条条取数据包，最多 5 条
    body = packet.response.body          # JSON 会自动变成 dict（字典）
    print('抓到：', packet.url)
    if isinstance(body, dict):       # isinstance = 判断是不是字典类型
        for row in body.get('data', []):
            # .get('data', []) = 取键 data，没有就给空列表
            u = row.get('file_url')   # 假设每条数据里有文件网址字段
            if u:
                urls.append(u)           # append = 加到列表末尾

print('共找到文件：', len(urls))
page = SessionPage()                   # 下载不必经过浏览器，用 SessionPage 更快
for u in urls:
    print(page.download(u, r'D:\downloads'))
    # download = 直接下载；返回 ('success', 路径)

browser.quit()

常见失败原因

① 一行「抓到」都没有 → 把 start() 挪到 get() 前面；或把目标字符串改短一点（只留域名或 api）。

③ 下载报 403 → 接口需要登录态或请求头，改用 tab.set.headers(...) 或直接让浏览器下载（download.by_browser()）。

26 常见问题与排错

把官网 QandA 和实战中最常遇到的报错集中在这里，按症状查。

症状原因怎么修
BrowserConnectError / 浏览器起不来找不到浏览器、端口被占、上次无头没关用 dp -p 设路径；结尾加 browser.quit()；或 co.headless(False) 关掉旧无头再启
程序结束了浏览器还开着官方行为：不自动关闭显式调用 browser.quit()；tab.close() 只关标签页
一直弹出「恢复页面 / 保存密码」气泡Chrome 默认提示co.set_pref('credentials_enable_service', False)、co.set_argument('--hide-crash-restore-bubble')
点元素报「该元素没有位置及大小」定位到了隐藏元素，或元素确实无尺寸先检查定位符是否命中同名元素；确无尺寸用 ele.click(by_js=True)（简写 click('js')）
找不到元素、代码却不报错返回 NoneElement，if 判断为假用 if not ele: 判断；调试时开 Settings.set_raise_when_ele_not_found(True)
文本里有 &nbsp; 匹配不上HTML 实体没转义写成 \u00A0；&gt; 写 \u003E（附录 A 有对照表）
无头模式「退不出来」上次无头进程被继续接管结尾 quit()；或 co.headless(False) 重启一次有头窗口
打包后报「找不到配置」ini 没跟 exe 放一起configs_to_here() 或 ChromiumOptions(read_file=False)
切换模式后数据为空s 模式不执行 js，动态渲染内容没了留在 d 模式，或改用监听直接拿接口数据
代码里写 ChromiumPage() 报 ImportError装的是 5.0，Page 对象已删除改成 Chromium().latest_tab（附录 C 有对照表）
get() 用 if tab.get(url): 判断失效5.0 返回 NavResult 而非 bool改成 if tab.get(url).ok:
Windows 专属排查清单

① 路径：一律用 r'D:\xxx' 或正斜杠，避免 \t \n 被当转义。
② 端口：默认 127.0.0.1:9222，多开换 9333 / 9111；端口被占时换一个或关掉旧浏览器。
③ 用户目录：新版 Chrome 不让直接用系统用户文件夹，5.0 的 use_system_user_path() 会复制一份；要稳定保留登录态，用 set_user_data_path() 指定专用目录。
④ 快捷方式加参数：右键 → 属性 → 目标末尾空一格加 --remote-debugging-port=9333，加之前先关掉所有 Chrome 窗口。
⑤ 中文乱码：写文件加 encoding='utf-8'；终端乱码可试 chcp 65001。
⑥ 窗口隐藏：set.window.hide() 只支持 Windows 且需 pip install pypiwin32。

排查问题的固定顺序

① 先看报错最后一行（真正的错误类型）；② 确认版本号（python -c "import DrissionPage; print(DrissionPage.__version__)"）；③ 确认定位符（print(ele) 看是不是 NoneElement）；④ 确认顺序（监听是不是先 start、配置是不是在启动前设）；⑤ 再查网络和端口。90% 的问题都在这五步里。

检查点

看到报错能先分清是「环境问题 / 版本问题 / 定位符问题 / 顺序问题」中的哪一类，就算学完了。
