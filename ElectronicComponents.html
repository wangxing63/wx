01 电子元器件到底是什么

先把「一板子小零件」拆成几大类，后面才不会越学越乱。

1.1 一句话定义

电子元器件：焊在电路板（PCB，Printed Circuit Board 印刷电路板）上，用来控制电流、储存能量、传递信号、感知外界、执行动作的最小独立零件。它们本身不能「思考」，但组合起来就是手机、电脑、电动车。

最有用的一个分类是按要不要外部供电才能工作：

大类英文特点包含哪些
无源元件Passive Components不需要额外电源；只能消耗、储存或释放能量，不能放大信号电阻、电容、电感、变压器、晶振（无源）、开关、连接器、保险丝
有源器件Active Devices需要供电；能放大、开关、产生电信号二极管、三极管、MOSFET、IGBT、晶闸管、所有 IC、有源晶振
机电 / 换能Electromechanical / Transducer把电变成动作/声音/光，或反过来继电器、电机、蜂鸣器、扬声器、麦克风、传感器、显示屏、电池
一个小坑

「无源」不等于「不重要」。一块板上数量最多的永远是无源元件，普通手机里有上千颗 MLCC；而故障率最高的往往也是电解电容、接插件这些「不起眼」的东西。

1.3 第三种分法：极性

有极性＝装反就不工作，甚至冒烟炸裂：铝电解电容、钽电容、超级电容、二极管、LED、三极管、MOS、所有 IC、电池、有源晶振、继电器线圈（部分）。

无极性＝两头随便装：普通电阻、MLCC、薄膜电容、色环电感、无源晶振、保险丝、磁珠、开关、连接器。

最容易记反的一对

铝电解电容身上印的是「−」白色条纹，标的是负极；钽电容身上印的是「+」或一道横杠，标的是正极。两者标记正好相反，第 38 章有对照图。

2.3 串并联：为什么板上要并那么多小电容

这里埋着一个测量陷阱

板上 10kΩ 电阻旁边如果并联了 1kΩ 的别的通路，万用表在路量出来就是 909Ω，不是 10kΩ。所以定量判断必须抬一脚，第 37 章会专门讲。

05 安全、静电与动手前准备（这章别跳过）

元件坏了可以换，人受伤不行。下面六条是每次动手前的固定动作。

5.1 统一前置流程 P0：断电 → 放电 → 抬一脚 → 选档 → 读数 → 判定

动手测任何元件，动手前先做这 4 步
1 拔掉电源、电池、USB 线，按一下开机键 # 让板上残余电荷有地方放掉；拔插头 ≠ 板上没电
2 用 DCV 档量主电源两端，确认 < 1V # DCV = Direct Current Voltage 直流电压档；< 1V 才算安全
3 大电容（≥100µF 或高压）用 10kΩ/2W 电阻跨接 5~30 秒 # 严禁拿螺丝刀直接短路，会打火、伤触点、吓一跳
4 至少脱焊抬起一只脚再定量测量 # 抬一脚 = 离线测量；不抬 = 在路测量，会被并联支路骗
你会看到：DCV 从几十伏慢慢掉到 0.0V；之后再测电阻，读数才稳定可信。若电压降不下来，说明还有电源接着，别继续测。

5.2 静电 ESD：看不见却能毁掉芯片

人体走过地毯能带几千伏静电，放电时间只有纳秒，人往往完全没感觉，但 MOSFET 的栅氧化层、CMOS 输入、LED、射频器件会被击穿。分两种后果：立即失效（当场坏）和潜在损伤（参数变差、时好时坏，最难查）。

5.4 市电与电池的红线

以下情况请停手

① 带电测市电一次侧：需要隔离变压器、差分探头、CAT III 以上表笔，新手不要独自操作。
② 锂电池：鼓包、漏液、破损立即停用；禁止用 Ω 档量电池内阻（等于短路）；禁止短路、过充、无保护板使用裸电芯。
③ 大容量电容 / 变频器母线：断电后仍可能存数百伏，必须按 5.1 放电并复测。
④ CRT / 高压模块：断电后仍有残余高压，普通万用表禁测。

5.5 一个最省事的判坏思路：对比法

思路不确定好坏时
1 找一块确定是好的同型号板，同样断电、同样档位、同样表笔极性 # 对比法不依赖绝对数值，最抗「在路测量」干扰
2 逐脚记录 阻值地图 # 把每个 IC 脚对 GND 的阻值写成一张表
3 两块板逐项对比，明显偏离的那一脚就是嫌疑点 # 注意电源脚本来就近 0Ω；要对比的是「相对差异」

① 电流互感器 CT 次级绝对不能开路：工作时次级开路会感应出上千伏，必须并联 burden 电阻或短接。

13 半导体与 PN 结基础（看懂后面七章的钥匙）

二极管、三极管、MOS、IGBT、LED、光耦，全都是同一块「P 型 + N 型」材料变出来的花样。

13.1 从硅到 PN 结

纯硅几乎不导电。掺入缺电子的杂质 → P 型（Positive，空穴多）；掺入多电子的杂质 → N 型（Negative，电子多）。把两者贴在一起，交界处就形成 PN 结，它只让电流朝一个方向走。

35.3 CC-CV 与 2026 充电口径

CC-CV = Constant Current–Constant Voltage 恒流恒压：先恒流把电压推到 4.20V，再保持恒压、电流逐渐衰减到 0.02~0.1C 截止（具体阈值需核实）。曲线长这样：电流恒定 → 电压升到 4.2V → 电流衰减。

PD 3.1 与电池的关系（2026）

PD3.1 的 240W 来自 28/36/48V @5A 的 EPR 扩展功率范围，需要充电器、设备、带 E-Marker 的 50V/5A 线缆三者都支持，否则充电器会把输出限制在 20V。48V 不会直接进电芯：先由充电 IC / 控制器降压，再由 BMS 按温度、SOC、SOH 限流，锂电仍走 CC-CV。240W 是上限不是恒定功率，小容量手机电池并不会因此充得更快。欧盟 (EU) 2022/2380 要求笔记本自 2026-04-28 起统一 USB-C 充电口；(EU) 2023/1542 新电池法的「便携电池用户可拆卸可更换」条款自 2027-02-18 起适用。

D.2 FAQ 二十问

问题答案
万用表显示 OL 是不是坏了？不一定。开路、超量程、二极管反偏、电容充满、以及 MOV/TVS/GDT/ESD/磁珠/晶振常态都会 OL。
贴片电阻「000」是坏件吗？不是，是 0Ω 跨接电阻，蜂鸣响才正常。
「103」是 103Ω 吗？不是，是 10×10³ = 10kΩ；用在电容上是 10000pF = 0.1µF。
铝电解和钽电容的标记一样吗？相反：铝电解「−」标负极，钽电容「+」标正极。
蓝白 LED 用二极管档不亮是坏吗？不是，多数表只输出 2~3V，点不亮 2.8~3.6V 的蓝白 LED。用 3V + 1kΩ 复验。
电解电容容量正常就一定是好的吗？不一定，ESR 变大是典型隐性失效，要用 ESR 表 100kHz 测。
共模电感两绕组之间不导通是坏吗？不是，绕组之间必须绝缘；0Ω 才是击穿。
磁珠用 Ω 档量到 0Ω 是短路吗？不是，那是 DCR；标称「600Ω」是 Z@100MHz，要网分测。
MLCC 容量档正常，板上却不够用？DC Bias：X7R/X5R 加直流偏压后有效容量掉 50~80%，换更高耐压 / 更大尺寸 / C0G。
为什么测 MOS 前要短接 G-S？栅极残留电荷会让 D-S 假导通，误判成击穿；放电后再测才准。
GaN 能用体二极管法判脚位吗？不能，横向 GaN 没有体二极管，必须查 datasheet 或专用测试。
无源晶振用万用表能量好坏吗？不能，只能查短路漏电；要上电用示波器 / 频率计或代换法。
SAW 滤波器各脚直流 OL 是坏吗？不是，正常；插入损耗与带外抑制要用网分测 S21/S11。
X2 安规电容能代 Y2 吗？绝对不能。Y 电容关系人身触电安全，等级与认证必须一致。
保险丝断了能用铜丝短接吗？绝对不能，会失去保护导致起火；必须换同电流、同电压、同快/慢断规格。
PPTC 动作后阻值变大是坏吗？不是，是保护状态；断电冷却应回落，不回落才是老化失效。
8Ω 喇叭量出 6.5Ω 是坏吗？不是，Ω 档量到的是直流电阻，通常 0.7~0.9× 标称阻抗。
锂电池能用 Ω 档量内阻吗？不能，等于短路；要带载压降法或专用内阻仪。
4.2V 充电器能给磷酸铁锂充电吗？不能，LFP 满充 3.65V，必须用专用充电器。
「PD 3.1」是 USB 3.1 吗？不是。PD 3.1 是供电规范（最高 240W），USB 3.1 是数据传输速率，版本号只是巧合。
