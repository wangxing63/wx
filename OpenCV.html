04 图像到底是什么

这一章是全书的地基：把图片拆成一个个数字。看懂了它，后面所有函数都只是「改数字」。

点一点：把一张图一层层拆开 可点
一张图还没拆开
shape像素ROI改数组
array.py写进文件
import cv2                            # 导入 OpenCV
import numpy as np                   # 导入 NumPy 并起别名 np（NumPy = 数值计算库）

img = cv2.imread('bird.jpg')       # 读图，得到数组
print('形状：', img.shape)       # shape = 数组尺寸；彩色是 (高, 宽, 3)
print('类型：', img.dtype)       # dtype = 每个数的类型，通常是 uint8

h, w = img.shape[:2]              # [:2] = 只取前两个数；h = 高，w = 宽
print('高宽：', h, w)

px = img[100, 150]                # img[y, x]：第 100 行、第 150 列的像素
print('这个像素（B,G,R）：', px)
# 注意是 [蓝, 绿, 红]，不是 RGB！

img[100, 150] = [255, 255, 255]   # 把这个点改成白色；= 是赋值
roi = img[50:200, 100:300]        # 切片：行 50~200、列 100~300 的一块区域 = ROI
print( ROI 形状：, roi.shape)

4.1 最容易记反的两件事

09 颜色空间

同一张图可以换好几种「记颜色的方式」。选对方式，找红色物体这种事会变得特别简单。

点一点：四种颜色空间分别用来干什么 可点
BGR（OpenCV 默认） img[y,x] = [12, 80, 210] 第 0 个是蓝，第 1 个绿，第 2 个红
转换统一用 cv2.cvtColor(图, 常量)；常量名里的方向就是转换方向，例如 COLOR_BGR2GRAY。
color.py写进文件
import cv2
import numpy as np

img = cv2.imread('bird.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)  # 彩色 → 灰度：三通道变一通道
hsv  = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)   # 彩色 → HSV：色相 H / 饱和度 S / 亮度 V
rgb  = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)   # 彩色 → RGB：给 matplotlib 显示前必做

lower = np.array([0, 60, 32])       # 下界：H、S、V 的最小值
upper = np.array([180, 255, 255])   # 上界：最大值
mask = cv2.inRange(hsv, lower, upper)
# inRange = 在区间内：落在上下界之间的像素变 255（白），其余变 0（黑）
# 得到的 mask 叫「掩码」，后面配合 bitwise_and 就能把目标抠出来
res = cv2.bitwise_and(img, img, mask=mask)
# bitwise_and = 按位与；mask 里是黑的地方结果也变黑
cv2.imwrite('mask.png', mask)
常量英文原意用途
COLOR_BGR2GRAYBGR to Gray灰度化；边缘检测、阈值、模板匹配前常做
COLOR_BGR2HSVBGR to HSV按颜色抠物体、目标跟踪
COLOR_BGR2RGBBGR to RGB交给 matplotlib / PIL 显示前必转
COLOR_GRAY2BGRGray to BGR灰度图要写进彩色视频、或要画彩色框时转回三通道
检查点

① 能写出 cvtColor 的三种常用转换。
② 知道 HSV 适合按颜色找物体。

10 图像算术与位运算

两张图相加会变亮，相减能找出差异，掩码能抠出一部分。这一章讲「图与图之间的运算」。

arith.py写进文件
import cv2
import numpy as np

a = cv2.imread('bird.jpg')
b = cv2.imread('bird2.jpg')
# 两张图必须「尺寸一样」，否则会报错；不一样先 resize

bright = cv2.add(a, a)                 # add = 逐像素相加，整体变亮
dark   = cv2.subtract(a, a)            # subtract = 相减，全变黑
diff   = cv2.absdiff(a, b)             # absdiff = absolute difference 绝对差，找两图不同之处
blend  = cv2.addWeighted(a, 0.7, b, 0.3, 0)
# addWeighted = 加权混合；公式 a*0.7 + b*0.3 + 0；最后一个 gamma 通常写 0

mask = np.zeros(a.shape[:2], np.uint8)
# 造一张和原图同高宽的单通道黑图，当掩码用；shape[:2] 只取高和宽
mask[100:300, 200:400] = 255           # 把中间一块涂白＝只保留这块
cut = cv2.bitwise_and(a, a, mask=mask)
# bitwise_and = 按位与；掩码为黑的地方结果变黑，白的保留
cv2.imwrite('blend.jpg', blend)
cv2.imwrite('cut.jpg', cut)
函数英文原意作用
cv2.add(src1, src2)add 加逐像素相加
cv2.subtract()subtract 减逐像素相减
cv2.multiply() / divide()乘 / 除调亮度、做归一化
cv2.absdiff()absolute difference 绝对差运动检测、找差异
cv2.addWeighted(a, α, b, β, γ)add weighted 加权加叠化、加水印、半透明
cv2.bitwise_and/or/not/xorbitwise 按位与/或/非/异或掩码抠图、反色、差异检测
最容易踩的坑：OpenCV 的加法不是普通加法

OpenCV 做的是饱和运算：200 + 100 不会变成 300 再溢出回绕，而是直接截断成 255；减法小于 0 截断成 0；除数为 0 结果设为 0。而 NumPy 的 a + a 是取模回绕（300 会变成 44）。想让亮度正常叠加，用 cv2.add() 而不是 +。

检查点

① 能用 addWeighted 把两张图叠在一起。
② 能用 bitwise_and + 掩码抠出一块。
③ 能说出饱和运算和 NumPy 加法的区别。

11 阈值处理

把彩色图变成只有黑白两色，是找轮廓、认文字之前最常用的一步。

点一点：五种阈值规则分别怎么变 可点
THRESH_BINARY 二值化 像素 > 127 → 255（白）；否则 → 0（黑） 最常用，做轮廓检测前的预处理
阈值一般对灰度图做；retval 是实际用到的阈值，dst 是结果图。
thresh.py写进文件
import cv2

gray = cv2.imread('bird.jpg', cv2.IMREAD_GRAYSCALE)
# IMREAD_GRAYSCALE = 直接读成灰度图，省一次 cvtColor
ret, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
# threshold = 阈值处理；127 = 分界线；255 = 超过后设成的值
# 返回两个值：ret = 实际用的阈值，binary = 处理后的黑白图

auto = cv2.adaptiveThreshold(gray, 255,
        cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 11, 2)
# adaptiveThreshold = 自适应阈值：每个小块自己算分界线，适合光照不均
# 11 = blockSize 邻域大小（必须奇数）；2 = C 从均值里减掉的常数

ret2, otsu = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
# OTSU = 大津法：阈值写 0，算法自动挑最合适的分界线
print('手动/自动阈值：', ret, ret2)
cv2.imwrite('binary.png', binary)
cv2.imwrite('otsu.png', otsu)
类型常量规则（像素值 > 阈值时）
THRESH_BINARY→ maxval（白）；否则 → 0
THRESH_BINARY_INV→ 0；否则 → maxval（黑白反过来）
THRESH_TRUNC→ 阈值本身；否则保持不变
THRESH_TOZERO保持不变；否则 → 0
THRESH_TOZERO_INV→ 0；否则保持不变
THRESH_OTSU不是单独用，要和上面某个相加，让算法自动定阈值
三个常见错误

① 直接对彩色图做 threshold → 先转灰度。
② adaptiveThreshold 的 blockSize 写成偶数 → 必须是奇数（3、5、11…）。
③ 忘了 threshold 返回两个值，写成 binary = cv2.threshold(...) 后面就会报「tuple 没有 shape」。

检查点

① 能写出 ret, dst = cv2.threshold(...) 并说出两个返回值。
② 知道 Otsu 时阈值写 0。
③ 知道 blockSize 必须是奇数。

12 平滑与滤波

照片有噪点、边缘检测前要降噪，都靠「拿周围像素平均一下」。

点一点：五种核分别有什么效果 可点
均值模糊 blur 核里全是 1/(5×5)，邻域取平均 去随机噪声，但边缘会糊
「核 kernel」是一个小矩阵，在图上从左到右、从上到下滑动；每滑到一个位置，就把覆盖的像素按核里的权重算出一个新值。
smooth.py写进文件
import cv2
import numpy as np

img = cv2.imread('bird.jpg')
mean  = cv2.blur(img, (5, 5))                # blur = 邻域取平均；(5,5) 是核大小
gauss = cv2.GaussianBlur(img, (5, 5), 0)    # 高斯模糊；第三参 sigmaX=0 表示按核大小自动算
median = cv2.medianBlur(img, 5)             # 中值模糊；核大小写「一个数」，且必须是奇数
bilat = cv2.bilateralFilter(img, 9, 75, 75)
# 双边滤波：9 = 邻域直径，75/75 = 颜色与空间的标准差，能保住边缘

kernel = np.array([[0, -1, 0], [-1, 5, -1], [0, -1, 0]])
# 自定义 3×3 锐化核；np.array = 造数组
sharp = cv2.filter2D(img, -1, kernel)
# filter2D = 用自定义核做卷积；-1 表示输出和原图同样的数据类型
cv2.imwrite('gauss.jpg', gauss)
cv2.imwrite('sharp.jpg', sharp)
函数英文原意擅长注意
blur(img, (5,5))blur 均值模糊去随机噪声边缘会一起糊掉
GaussianBlur(img, (5,5), 0)Gaussian 高斯模糊通用降噪，Canny 前常用核大小要奇数
medianBlur(img, 5)median 中值模糊专治黑白噪点（椒盐噪声）参数是一个奇数
bilateralFilter(img, 9, 75, 75)bilateral 双边滤波去噪还保边、磨皮比较慢
filter2D(img, -1, kernel)filter 2D 二维卷积锐化、浮雕、自定义效果-1 ＝保持原类型
检查点

① 能说出高斯模糊和中值模糊各治什么噪声。
② 知道 medianBlur 的核必须是奇数。
③ 能用 filter2D + 自定义核做锐化。

13 形态学操作

二值图里总有小白点、小黑洞。腐蚀和膨胀就是专门「修形状」的工具。

morph.py写进文件
import cv2
import numpy as np

gray = cv2.imread('bird.jpg', cv2.IMREAD_GRAYSCALE)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
# _ 是一个「我不关心」的变量名，接住第一个返回值

kernel = np.ones((5, 5), np.uint8)     # 造 5×5 全 1 的核；ones = 全一；uint8 = 0~255 整数
eroded = cv2.erode(binary, kernel, iterations=1)
# erode = 腐蚀：白色前景收缩，去掉小白点；iterations = 做几次
dilated = cv2.dilate(binary, kernel, iterations=1)
# dilate = 膨胀：白色前景扩张，补上小黑洞

opened = cv2.morphologyEx(binary, cv2.MORPH_OPEN, kernel)
# MORPH_OPEN = 开运算：先腐蚀再膨胀，专门去小白噪点
closed = cv2.morphologyEx(binary, cv2.MORPH_CLOSE, kernel)
# MORPH_CLOSE = 闭运算：先膨胀再腐蚀，专门填小孔、连断开的笔画
grad = cv2.morphologyEx(binary, cv2.MORPH_GRADIENT, kernel)
# MORPH_GRADIENT = 膨胀减腐蚀，得到物体轮廓
cv2.imwrite('opened.png', opened)
操作英文原意先做什么效果
erode()erode 腐蚀—白色区域变小
dilate()dilate 膨胀—白色区域变大
MORPH_OPENopening 开运算腐蚀 → 膨胀去掉孤立小白点
MORPH_CLOSEclosing 闭运算膨胀 → 腐蚀填小洞、连邻近物体
MORPH_GRADIENTgradient 梯度膨胀 − 腐蚀抠出轮廓线
MORPH_TOPHAT / BLACKHATtop hat / black hat原图 − 开 / 闭 − 原图提亮细节 / 提暗细节
记忆口诀

开运算去白点，闭运算补黑孔。核越大、iterations 越多，效果越猛，但也越容易把本来要保留的细节吃掉。

16 轮廓检测

边缘是「线」，轮廓是「一整圈点的集合」，能算面积、周长、外接框，是数物体的关键。

contour.py写进文件
import cv2

img = cv2.imread('bird.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
_, binary = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
# 找轮廓前必须二值化：黑背景 + 白物体

contours, hierarchy = cv2.findContours(binary, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)
# findContours = 找轮廓；RETR_TREE = 保留全部层级；CHAIN_APPROX_SIMPLE = 只留端点省内存
# 返回 contours（轮廓点列表）和 hierarchy（谁套着谁）

cv2.drawContours(img, contours, -1, (0, 255, 0), 2)
# drawContours = 画轮廓；-1 = 画全部；绿色；线宽 2。注意它直接改原图，不返回新图

for c in contours:
    area = cv2.contourArea(c)                 # contourArea = 轮廓面积
    if area < 100:                          # 太小的多半是噪点，跳过
        continue                           # continue = 跳过本次循环，看下一个
    x, y, w, h = cv2.boundingRect(c)          # boundingRect = 外接正矩形 (左上角 + 宽高)
    cv2.rectangle(img, (x, y), (x+w, y+h), (255, 0, 0), 2)
    peri = cv2.arcLength(c, True)            # arcLength = 周长；True = 轮廓闭合
    approx = cv2.approxPolyDP(c, 0.01 * peri, True)
    # approxPolyDP = 用更少的点近似轮廓；0.01*周长 = 近似精度
    print('面积/周长/顶点数：', area, peri, len(approx))

cv2.imwrite('contours.jpg', img)

RETR_EXTERNALretrieve external 只取外层只找最外面一圈，最快
RETR_LIST / RETR_TREElist / tree 列表 / 树全部轮廓 / 全部并保留嵌套层级

① 知道找轮廓前要二值化。
② 能画出外接矩形并过滤掉太小的轮廓。

19.2 MeanShift / CamShift：跟着目标跑

meanshift.py写进文件
import cv2
import numpy as np

cap = cv2.VideoCapture('video.mp4')
ret, frame = cap.read()
x, y, w, h = 300, 200, 100, 50           # 初始跟踪窗口：左上角 (x,y)，宽 w 高 h
track_window = (x, y, w, h)

roi = frame[y:y+h, x:x+w]                 # 从第一帧里切出目标区域 ROI
hsv_roi = cv2.cvtColor(roi, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv_roi, np.array((0., 60., 32.)), np.array((180., 255., 255.)))
# inRange = 只保留有一定饱和度、亮度的像素，去掉暗部干扰
roi_hist = cv2.calcHist([hsv_roi], [0], mask, [180], [0, 180])
# 只统计 H（色相）通道的直方图，作为「目标长什么样」的指纹
cv2.normalize(roi_hist, roi_hist, 0, 255, cv2.NORM_MINMAX)
# normalize = 归一化，把数值拉到 0~255，方便后面算概率
term_crit = (cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 10, 1)
# 停止条件：最多迭代 10 次，或移动小于 1 像素就停；| 是「按位或」，把两个标志合起来

while True:
    ret, frame = cap.read()
    if not ret: break
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    dst = cv2.calcBackProject([hsv], [0], roi_hist, [0, 180], 1)
    # calcBackProject = 反向投影：算出每个像素「像目标」的概率图
    ret, track_window = cv2.meanShift(dst, track_window, term_crit)
    # meanShift = 把窗口往概率最大的地方挪；返回新窗口位置
    x, y, w, h = track_window
    cv2.rectangle(frame, (x, y), (x+w, y+h), 255, 2)
    cv2.imshow('跟踪', frame)
    if cv2.waitKey(30) & 0xFF == 27: break
    # 27 = Esc 键的 ASCII 码
cap.release(); cv2.destroyAllWindows()
方法英文原意区别
meanShift()mean shift 均值漂移窗口大小固定，只挪位置
CamShift()continuously adaptive mean shift窗口大小和角度也会跟着变
calcBackProject()back projection 反向投影把直方图变成「哪里像目标」的概率图
这套方法的边界

MeanShift / CamShift 靠颜色直方图认目标：目标被遮挡、快速运动、或背景里有同色物体时容易跟丢。做严肃项目时，一般用第 26 章提到的专用跟踪器或 DNN 检测器。

20 特征匹配与图像拼接

两张照片拍的是同一片风景，怎么自动拼起来？靠「找两图里相同的特征点」。

stitch.py写进文件
import cv2
import numpy as np

img1 = cv2.imread('left.jpg'); img2 = cv2.imread('right.jpg')
g1 = cv2.cvtColor(img1, cv2.COLOR_BGR2GRAY)
g2 = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)

sift = cv2.SIFT_create()               # SIFT = 尺度不变特征变换；5.0 仍在主库，可直接用
kp1, des1 = sift.detectAndCompute(g1, None)
# detectAndCompute = 一次完成「找关键点 kp」和「算描述子 des」；None = 不用掩码
kp2, des2 = sift.detectAndCompute(g2, None)

bf = cv2.BFMatcher()                   # BFMatcher = Brute Force 暴力匹配器
matches = bf.knnMatch(des1, des2, k=2)
# knnMatch = 给每个特征点找 2 个最像的候选；k=2 是后面比率测试的前提
good = []
for m, n in matches:                # m = 最像的，n = 第二像的
    if m.distance < 0.75 * n.distance:  # Lowe 比率测试：最像的要明显比第二像的更像
        good.append(m)                # append = 加入好匹配列表

if len(good) > 10:                    # 匹配太少就拼不准
    src = np.float32([kp1[m.queryIdx].pt for m in good]).reshape(-1, 1, 2)
    dst = np.float32([kp2[m.trainIdx].pt for m in good]).reshape(-1, 1, 2)
    # queryIdx/trainIdx = 匹配两端特征点的编号；reshape(-1,1,2) = 整理成函数要的形状
    H, _ = cv2.findHomography(src, dst, cv2.RANSAC, 5.0)
    # findHomography = 求单应矩阵 H；RANSAC = 自动剔除错误匹配；5.0 = 重投影阈值
    h1, w1 = img1.shape[:2]; h2, w2 = img2.shape[:2]
    result = cv2.warpPerspective(img1, H, (w1 + w2, h1))
    # warpPerspective = 按 H 把第一张图「掰」到第二张的视角
    result[0:h2, 0:w2] = img2          # 再把第二张贴上去
    cv2.imwrite('panorama.jpg', result)
else:
    print('好匹配太少，换两张重叠更多的照片')

SIFT_create()Scale-Invariant Feature Transform找尺度不变的特征点（5.0 仍在主库）
ORB_create()Oriented FAST and Rotated BRIEF更快的二值特征，适合实时
detectAndCompute()detect and compute一次拿到关键点与描述子

# matchTemplate = 拿小图在大图上滑动，每个位置算一个相似度
# 返回二维结果矩阵 res；TM_CCOEFF_NORMED 是归一化相关系数，越接近 1 越像

方法常量怎么判断「最像」

TM_CCOEFF / TM_CCOEFF_NORMED相关系数，越大越像（最常用）

import cv2                          # 导入 OpenCV
import os                           # os = operating system 操作系统，用来列文件夹

IN_DIR, OUT_DIR = 'in', 'out'  # 常量：输入/输出文件夹名，大写表示不改
os.makedirs(OUT_DIR, exist_ok=True)
# makedirs = make directories 建文件夹；exist_ok=True = 已存在也不报错

count = 0                            # 计数器，最后打印处理了几张
for name in os.listdir(IN_DIR):  # listdir = 列出文件夹里所有名字
    if not name.lower().endswith(('.jpg', '.png')):
        # lower() = 转小写；endswith = 以…结尾；不是图片就跳过
        continue
    path = os.path.join(IN_DIR, name)
    # os.path.join = 把文件夹和文件名拼成完整路径（自动处理斜杠）
    img = cv2.imread(path)
    if img is None:              # 读失败不报错，只返回 None，必须判空
        print('跳过（读不到）：', name)
        continue

    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)  # 转灰度
    small = cv2.resize(gray, (640, 480))          # 统一缩到 640×480（宽,高）
    eq = cv2.equalizeHist(small)                  # 直方图均衡，拉开对比度
    out_path = os.path.join(OUT_DIR, name)
    ok = cv2.imwrite(out_path, eq)                # 存盘，返回 True / False
    print(name, '→', '成功' if ok else '失败')
    count += 1                                   # += 表示「自己加 1」

print('全部完成，共处理', count, '张')
