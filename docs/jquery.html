01

初识 jQuery：一位改变网页历史的管家

二十年前它统一了浏览器江湖，今天它依旧守着上千万个网站——先认识这位老朋友，再决定怎么跟它学

2006 年 1 月 14 日，纽约 BarCamp 技术聚会上，一位叫 John Resig 的年轻程序员发布了一支只有几十 KB 的 JavaScript 小工具。整整二十年后——2026 年 1 月 17 日，jQuery 团队发布了它近十年来的第一个大版本：jQuery 4.0.0。这门课，就从「它到底是谁、凭什么活到今天」讲起。

1.1 jQuery 是什么：网页的万能遥控器

类比把网页想成一面巨大的电视墙，上面成百上千块小屏幕（HTML 元素）各演各的。原生 JavaScript 是手动挡——你得走到每块屏幕跟前拧旋钮；jQuery 是一支万能遥控器——对着一排屏幕按一个键，整排同时换台。

jQuery 的口号只有四个词：Write Less, Do More（写得少，做得多）。到底少写多少？同一件事，两种写法摆在一起看：

文件：compare.js
// ===== 任务：把页面上所有 <p> 段落的文字变成红色 =====

// 写法一：原生 JavaScript（手动挡）
var list = document.querySelectorAll("p");   // 变量 list：用原生函数 querySelectorAll 查出页面上所有 <p> 元素，得到一个"类数组"
for (var i = 0; i < list.length; i++) {      // for 循环：必须自己写计数器 i、自己判断边界、自己 i++
    list[i].style.color = "red";             // 属性 style.color：每个元素都要单独拧一次旋钮——行内样式设为红色
}

// 写法二：jQuery（自动挡）
$("p").css("color", "red");                  // 函数 $：jQuery 的"抓屏键"——一口气圈住所有 <p>；方法 .css()：一键把整支军团全部染红
两种写法效果完全相同：页面上所有段落同时变红——但 jQuery 只用了一行。

一行顶六行，而且不用写循环、不用记一堆名字冗长的原生 API。这一行里出现了两位贯穿全书的主角：$（抓屏键，第 3 章精讲）和 .css()（染色键，第 8 章精讲）。后面 19 章要学的，本质上都是遥控器上各式各样的「键」。

1.2 它凭什么火：浏览器大战年代的救世主

2006 年的网页开发是「黑暗年代」：微软 IE 一套 API，火狐、Safari 一套标准 API，同一个功能要写两三遍代码、按浏览器分发。jQuery 出现后，把两套方言翻译成了一种统一语法：

你的需求原生写法当年要操心的事jQuery 替你扛下
绑一个点击事件IE 用 attachEvent，标准浏览器用 addEventListener，参数还不同.on("click", fn) 一种写法走天下
拿一批元素getElementById / getElementsByTagName / querySelectorAll 新老混杂$(".card") 与 CSS 完全同一套口诀
改样式厂商前缀（-webkit- 等）各不相同.css() 自动处理兼容
做动画自己写 setInterval 逐帧挪位置.animate() 一行搞定
发请求XMLHttpRequest 三代版本差异$.ajax() 一把梭
历史冷知识今天的浏览器已经统一了很多——当年 jQuery 扛的那座「兼容性大山」，现代浏览器大多已铲平。所以 jQuery 的现代价值，从「兼容性救世主」变成了极度顺手的操作语法 + 二十年攒下的成熟生态。这也是它至今仍活在上千万网站里的原因。

1.3 今天的 jQuery：谁还在用它？

  • WordPress 生态：官方前台与海量主题、插件仍以 jQuery 为地基，改不动也不想改；
  • 老项目维护：无数企业内部系统、管理后台是「jQuery + Bootstrap」盖起来的楼——会修缮它就是饭碗；
  • 轻量交互页：落地页、活动页——引一个 30KB 的库解决全部交互，比引一整套构建工具划算得多；
  • 学习价值：jQuery 的 API 设计（链式调用、隐式迭代）是后来所有现代库的启蒙老师。学懂它，再看 Vue、React 会觉得处处眼熟。

那它和 Vue、React 什么关系？一句话：定位不同，不冲突。

对比项jQueryVue / React
做什么顺手操纵已有页面的 DOM接管整个页面的渲染与状态

学习曲线平缓——就是 JavaScript 加一套好用的工具较陡——组件、状态、构建工具一样不少
别信「jQuery 已死」它只是不再站在聚光灯下。它仍是世界上部署最广的 JavaScript 库之一；而 2026 年 jQuery 4.0 的正式发布（二十周年纪念之作）证明这支团队仍在认真维护它。对零基础的你，它更是理解「网页交互原理」最平缓的一座桥。

1.4 jQuery 4.0：二十岁生日的大扫除

2026 年 1 月 17 日发布的 4.0.0，是 jQuery 近十年来第一个大版本。官方博客称之为一次「现代化大扫除」——主线是甩掉包袱、拥抱现代：

  • 甩掉历史包袱：13 个老掉牙的工具函数退役（$.trim、$.parseJSON 等——原生 JS 早有更好的替身，第 17 章给全表）；
  • 告别老浏览器：IE10 及更早版本不再支持（IE11 暂留，jQuery 5 再送走）；
  • 拥抱现代工程：源码迁移到 ES Modules、改用 Rollup 打包——Vite / Webpack 项目里可以像普通 npm 包一样 import $ from "jquery"；
  • 安全升级：支持 Trusted Types，在开了 CSP（内容安全策略）的页面也能安全干活；
  • 瘦身成功：删除老 IE 兼容代码后，gzip 体积再减 3KB+；slim 精简版只剩约 19.5KB。
版本前提本教程全部内容基于 jQuery 4.x（发布版 4.0.0）。如果你在维护 3.x 老项目：全书 95% 内容通用，差异集中在第 17 章「迁移指南」——那里把 4.0 的每一条破坏性变更都列成了对照表。

1.6 开箱热身：控制台里先玩三分钟

看完概念先别急着搭工程——打开任意网页按 F12，切到 Console（控制台）标签，输入下面三行，立刻体验「遥控器指哪打哪」的感觉（前提是该页面引入了 jQuery；没有的话，先在自己电脑上新建一个最小页面，第 2 章手把手教）。

热身：三行代码的魔法（控制台直接敲）
$("*").length;                            // 选择器 "*"(通配)：页面上所有元素——.length：一共圈到几个（遥控器全频道扫描）
$("p").css("color", "red");              // 选择器 "p"：所有段落 → .css()：一口气全染红（广播式！一行顶一个循环）
$("a:first").text("被遥控器换掉的链接");   // 选择器 "a:first"：第一个链接 → .text()：原地换文字——页面立刻变了
为什么现在就能玩这三行浓缩了全书骨架：选人（选择器）→ 干活（方法）→ 生效（隐式迭代）。原生 JS 写同样效果至少各要三五行循环——「写得更少，做得更多」不是口号，是此刻你亲眼所见。

零基础也得带够干粮——HTML/CSS/JS 三件套最小必备包，加上让 jQuery 正式上桌的三种引入姿势

2.1 网页的三大原材料

类比一个网页 = 一栋房子：HTML 是钢筋骨架（决定有几个房间、各叫什么），CSS 是装修皮肤（决定墙什么色、家具有多大），JavaScript 是电路与仆人（灯一亮人一来就动起来）。jQuery 只是一套特别好使的电动工具——它动手的对象，始终是前两样搭起来的东西。
原材料管什么本教程你需要会的
HTML骨架与内容标签、class、id（2.2 的最小骨架够用）
CSS外观样式「选择器 = 点名口诀」的三种基本喊法（2.3）
JavaScript行为与交互变量、函数、对象、数组四件套（2.4）

2.2 HTML 最小骨架：每个标签都有名有姓

文件：skeleton.html
<!DOCTYPE html>                          <!-- DOCTYPE：向浏览器声明"这是 HTML5 文档"，必须放在第一行 -->
<html lang="zh-CN">                        <!-- html：整栋楼的根标签；lang 属性：内容是中文（帮助读屏与翻译） -->
<head>                                     <!-- head：楼房"图纸间"——放看不见的配置信息 -->
    <meta charset="UTF-8">                 <!-- meta charset：声明编码为 UTF-8——没有它中文会变乱码 -->
    <title>我的网页</title>                 <!-- title：浏览器标签页上显示的标题 -->
    <link rel="stylesheet" href="style.css">   <!-- link：引入外部 CSS 样式表（rel 表明关系是样式表） -->
</head>                                    <!-- /head：图纸间到此结束 -->
<body>                                     <!-- body：楼房"营业区"——用户看得见的一切都放这里 -->
    <h1 id="title">大标题</h1>             <!-- h1：一级标题；id="title"：它的身份证号，全页唯一 -->
    <p class="intro">一段介绍文字。</p>     <!-- p：段落；class="intro"：它的外号，可重复——同外号的元素算一队 -->
    <script src="app.js"></script>         <!-- script src：引入外部 JS 文件；放在 body 末尾=骨架建完才跑脚本（第 3 章详解） -->
</body>                                    <!-- /body：营业区结束 -->
</html>                                    <!-- /html：整栋楼结束 -->
标签速记标签成对出现（<p> 开、</p> 关）；id 是身份证号（全页唯一），class 是外号（可重复、可多个）——这个区分第 4 章选择器马上用到。

2.3 CSS 点名口诀 30 秒速成

CSS 用「选择器」决定样式给谁——而 jQuery 挑元素的正是同一套口诀（第 4 章你就明白了）。三种基本喊法：

文件：style.css
p { color: #333333; }        /* 标签选择器：按"姓氏"点名——页面上所有 p 标签全部选中 */
.intro { padding: 16px; }    /* 类选择器：按"外号"点名——class="intro" 的所有元素（注意前面有个点） */
#title { color: #c0392b; }   /* ID 选择器：按"身份证号"点名——id="title" 的那一个元素（注意前面有个井号） */

2.4 JavaScript 存量四件套

文件：basics.js
var price = 25;                          // 变量 price：一个贴了名字的盒子，存数字 25（var 声明；也可以用 let）
var name = "鼠标";                        // 变量 name：盒子也能装字符串（一段文字，用引号包住）

function cheer(word) {                   // 函数 cheer：一段打包好的活，名叫 cheer；参数 word：调用时塞进来的原料
    return "买了一个" + word + "!";        // 关键字 return：干完活交回的结果（+ 号在字符串之间表示"拼接"）
}
cheer(name);                             // 调用函数：塞进 name，得到 "买了一个鼠标!"（浏览器控制台里能打印验证）

var goods = { name: "键盘", price: 199 }; // 变量 goods：对象——花括号包住的一组"键: 值"（像一张登记表）
goods.price;                             // 属性访问：点号取货，得到 199（goods.name 得到 "键盘"）
goods["price"];                          // 方括号也能取货——键名是字符串或变量时用这种

var carts = ["苹果", "香蕉", "橙子"];       // 变量 carts：数组——方括号包住的一列值，从 0 开始编号
carts[0];                                // 索引访问：取第 0 个，得到 "苹果"（注意不是第 1 个！）
就这么多吗看懂本书，这四件套（变量、函数、对象、数组）真的够了。遇到看不懂的语法别慌——每行都有中文注释，跟着注释的思路走；想系统补 JS 基础，回头找一本 JavaScript 入门教程即可。

2.5 引入 jQuery：三种上桌姿势

2.6 姿势一：CDN 引入（最常用）

CDN（Content Delivery Network，内容分发网络）= 分布在全球的「公共仓库」——浏览器从离你最近的仓库取 jQuery，不用自己下载保存：

文件：任意 .html 的 <body> 末尾
<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>   <!-- script src：从 jQuery 官方 CDN 引入 4.0.0 压缩版——一行就完成安装！ -->
CDN写法特点
jQuery 官方https://code.jquery.com/jquery-4.0.0.min.js发布最快、最权威（本教程默认）
jsDelivrhttps://cdn.jsdelivr.net/npm/jquery@4.0.0/dist/jquery.min.js国内访问通常更稳
cdnjs / unpkghttps://cdnjs.cloudflare.com/ajax/libs/jquery/4.0.0/jquery.min.js 等同类公共仓库，任选
顺手加一道保险CDN 文件还能加 SRI 完整性校验（integrity 属性，一串文件指纹，被篡改就拒绝加载）——去 releases.jquery.com 点对应版本即可复制带指纹的完整标签。学习阶段可先不加。

2.7 姿势二：下载到本地

不想依赖外网（内网开发、离线演示）？去 jquery.com/download 右键「链接另存为」，把文件放进项目文件夹：

文件：任意 .html（本地引入版）
<script src="js/jquery-4.0.0.min.js"></script>   <!-- src 换成本地相对路径：js 文件夹里的压缩版（先建 js 文件夹、把下载的文件放进去） -->
下载文件是什么什么时候用
jquery-4.0.0.min.js压缩版（min）：挤掉空格换行，体积小生产环境、日常学习（默认选它）
jquery-4.0.0.js未压缩版：带完整变量名与注释想读 jQuery 源码、调试进库内部时
jquery-4.0.0.slim.min.js精简版：约 19.5KB，不含 ajax / effects 模块，4.0 还移除了 Deferred 与 Callbacks只用 DOM 操作、要极限瘦身时（教程别用——第 14 章 AJAX 会报「不是函数」）

第一行代码：工厂函数 $ 与就绪信号

解开两大悬念：$ 到底是什么？代码为什么要等 DOM 就绪才动手？——想通这两件事，jQuery 的世界观就通了

每个 jQuery 程序都长一个样：先用 $() 圈人，再对圈住的人按方法键。这一章解剖 $ 函数的真身、它的四种「食材」，以及新手第一大坑——代码跑得太早、页面还没建好。

3.1 $ 的真身：一个函数，两个名字

类比$ 不是什么魔法符号，就是一个函数名——只是恰好只有一个字符，敲起来飞快。它是 jQuery 函数的昵称，就像「罗伯特」的小名「鲍勃」：$ === jQuery，指的是同一个函数。
浏览器控制台
typeof jQuery               // 操作符 typeof：查类型——返回 "function"，说明 jQuery 是个函数
jQuery.fn.jquery           // 属性 .fn.jquery：版本号 "4.0.0"（fn 是 prototype 的别名）
$ === jQuery               // 严格相等：true——$ 与 jQuery 是同一个函数
"function"
"4.0.0"
true

它为什么被叫做「工厂函数」？因为你每次调用它，它都生产一件新产品——一个 jQuery 对象（下一节细说）。调用要带括号：$()；只写 $ 是函数本身，写了 $() 才是「调用了一次」。

3.2 $() 的四种食材

遥控器的抓屏键能吃四种东西，产出各不相同：

喂给它什么写法示例产出
选择器字符串（最常用）$("#title")、$(".card")圈住匹配的元素，组成 jQuery 对象（军团）
HTML 片段字符串$("<p>你好</p>")当场造出一个新元素（第 10 章主角）
原生 DOM 元素$(document)、$(e.target)把原生元素「穿上 jQuery 制服」变成军团
函数$(function () { ... })等 DOM 就绪后执行这个函数（3.4 的简写！）
认材质的门道同样是字符串，以 < 开头的当 HTML 片段（造新元素），其他的当选择器（找旧元素）——$("<p>") 是造，$("p") 是找，一字之差天壤之别。

3.3 就绪信号：为什么你的代码总「扑空」

浏览器读 HTML 是从上往下、边读边建的，像流水线装配。如果你的脚本放在 <head> 里，它执行时身体（body）还没装配——这时去 $("#title")，自然两手空空。先看懂这条时间线：

文件：ready_demo.js

    $("#title").text("我等到你了！");   // 此刻再抓 #title，稳稳抓到——方法 .text()：改它的文字内容
});

// 简写（完全等价，老兵都这么写）：
$(function () {                       // $ 直接吃「函数」食材 = ready 的官方快捷方式（3.2 表里的第四种食材就是它）
    $("#title").text("简写也一样！");
});
新旧名词老教程里常见的 $(document).load(fn)、$(window).load(fn) 这类「load 绑定」写法在 jQuery 3.0 就移除了——统一用 $(fn)（等骨架）或 $(window).on("load", fn)（连图片都等完，很少需要）。

3.4 script 放哪：两派都行，别「悬空」

两种合法摆位（选一种坚持）

    <script>$(function () { /* 代码 */ });</script>                        <!-- 包上 ready 等骨架建好 -->

// 派别二：放 </body> 前——此刻骨架已建完，可省 ready（本教程的默认摆位）

3.8 就绪信号全家福：三种写法与一个刹车

3.3 节讲了「为什么要等 DOM 就绪」，这里把 ready 的全部写法一次列全——三种合法姿势加上一个罕见的高级刹车，顺带认清一个早已移除的坑写法。

文件：ready_family.js

    console.log("就绪姿势一");

$(document).ready(function () {           // 方法 .ready()：显式写全——可读性更直白，长度多一截
    console.log("就绪姿势二");
});

$.holdReady(true);                        // 方法 $.holdReady(true)：踩住刹车——暂停就绪事件的放行
$.get("/config.json", function () {       // 典型场景：必须先加载一份配置文件……
    $.holdReady(false);                   // ……拿到配置后才松刹车（false）——此刻 ready 才真正触发
});
// 用途：页面初始化强依赖某个前置请求时（插件配置、权限信息），其余 99% 场景用不上

// —— 坑写法（早已移除，见到就改）——
// $(document).on("ready", fn);           // ❌ "ready" 伪事件 3.0 已废弃移除——现在绑了也永远不响
// $("img").ready(fn);                    // ❌ 老版本允许给任意元素绑 ready——毫无意义，早已废除
别把 ready 和 load 混为一谈$(fn) 等 DOM 树建好就触发（快）；$(window).on("load", fn) 要等图片等资源全部下载完才触发（慢）。绝大多数交互逻辑该用前者；只有「必须知道图片实际尺寸」的场景才等 load——第 9 章尺寸课会再遇到它。

5.3 jQuery 专属口诀与性能账本

CSS 原生没有的选择器（:contains、:has、:even 等）jQuery 依然支持，但引擎无法一步交给浏览器，得先粗选再逐个细查——人多时就慢：

文件：perf.js（快慢对照）

    return $(this).text().indexOf("缺货") > -1;   // 原生方法 .indexOf()：包含则返回下标，不包含返回 -1
}).addClass("lack");

// 慢：$(":contains(...)"直接扫全页)—— ":xxx" 裸过滤器开头还要先全页点名，更慢
// 快：永远给个范围前缀，如 $(".goods td")
性能三原则① 给范围：别让选择器从全页扫起——$(".goods td") 比 $(":contains(...)") 快一个量级；② id 起手：$("#list").find("li")（find 方法 6 章讲）比 $("ul li") 在大页面上快；③ 专属口诀后置：jQuery 专属过滤器（:even/:contains/:eq…）尽量拼在原生选择器后面，让原生引擎先干粗活。

方法挑谁与选择器版的关系
.filter(sel / fn)符合条件 / 面试通过的.filter(":even") ≈ $("li:even")，但更快（5.3 讲过）
.not(sel / fn)不符合的（filter 的反面）≈ :not()

6.2 家谱导航：上下楼串门

方法去哪要点
.children([sel])亲儿子们只下一层；可带筛选

.siblings([sel])兄弟姐妹（不含自己）做「点谁谁亮」必用

.nextAll() / .prevAll()后面的 / 前面的所有同层可带筛选

6.3 find 与 end：链式调用的撤销键

链式调用（一个点接一个点）是 jQuery 的招牌优雅。但串门之后怎么回到原来的队伍？—— .end()：

文件：chain_end.js
$("ul")                    // 圈住 ul 军团（栈：[ul]）
    .children()             // 方法 .children()：串门到孩子们（栈：[ul, li 们]）
        .css("color", "#333")   // 给孩子们统一设色
    .end()                  // 方法 .end()：撤销上一次"换队伍"——回到 [ul]
    .addClass("styled");    // 给 ul 加类——没有 end() 这行就会错加到 li 身上！

$("ul").find(".hot")       // 方法 .find(".hot")：翻遍后代找 hot（栈：[ul, hot 们]）
    .css("color", "red")
    .end()                  // 撤销——回到 [ul]
    .find(".cold")          // 再翻一次找 cold（栈：[ul, cold 们]）
    .css("color", "blue");  // 两队各染各的——一句链全办完

// .addBack()：把"现在的队伍"与"撤销前的队伍"合并
$("li.active").nextAll().addBack();   // 方法 .addBack()：后面的兄弟 + 自己 ——常见于"点谁谁和后面全亮"
类比jQuery 内部给每次「换队伍」（children/find/filter/parents…）都留了底——像浏览器的「后退」按钮。.end() 就是点一下后退；连点两次退两步。只写值不改队的方法（css/text/on…）不进栈，所以可以无限链下去。

jQuery 对象解剖：军团的真身

它看着像数组、用着像数组，但它不是数组——认清军团结构，掌握「写广读窄」铁律，从此不再糊涂

全书用到现在，该解剖主角了。jQuery 对象（军团）到底是什么结构？原生 DOM 元素怎么和它互相转换？为什么设置样式「全员生效」、读取样式「只报一个」？——这一章是地基中的地基，想通它，后面所有 API 都是透明 的。

7.1 军团 = 「类数组」的包装盒

文件：anatomy.js
var $lis = $("li");                  // 变量 $lis：jQuery 军团

$lis.length;                         // 属性 .length：军团人数（不是方法——不带括号！）
$lis[0];                             // 下标 [0]：取出第 1 个成员——注意！是「原生 DOM 元素」（便服）
$lis.eq(0);                          // 方法 .eq(0)：第 1 个成员——但「穿着 jQuery 制服」（军团）
$lis[0].textContent;                 // 原生元素只能用原生方法：.textContent 取文字
$lis.eq(0).text();                   // 军团用 jQuery 方法：.text() 取文字——两者等价

$lis.get();                          // 方法 .get()（无参）：整支军团还原成原生数组
$lis.get(0);                         // 方法 .get(0)：取第 1 个——与 $lis[0] 等价
Array.from($lis);                    // 原生函数 Array.from()：也能把"类数组"转成真数组（顺便印证它长得像数组）
[0] 与 eq(0) 的世纪之坑$lis[0] 给你裸元素（再调 .css() 直接报错「不是函数」）；$lis.eq(0) 给你军团（全套方法可用）。想对单个元素用 jQuery，永远 eq()；下标取出的记得重新穿制服：$($lis[0])。

7.3 隐式迭代：写广读窄铁律

类比军团的方法像广播喇叭：设置类操作一声令下、全员执行（这叫「隐式迭代」——你不用写循环，jQuery 替你循环）；读取类操作却只问队首一个人——全军的数据没法一句报齐。
文件：implicit.js
$("li").css("color", "red");          // 写：广播——所有 li 全变红（隐式迭代）
$("li").text("统一文字");              // 写：广播——全员文字统一

$("li").css("color");                 // 读：只报队首的颜色！不是所有人的（想全部拿？.each 自己收集）
$("li").text();                      // 读：唯一例外——.text() 会把所有人的文字拼接成一整串返回
$("li").val();              // 读：文本框的值——同样只取队首

// 想读全部？两个姿势：
var colors = [];                     // 变量 colors：收集袋
$("li").each(function () {           // 姿势一：.each() 手动点名
    colors.push($(this).css("color"));   // 原生数组方法 .push()：装袋
});
var colors2 = $("li").map(function () {   // 姿势二：.map() 流水线（返回军团，再 .get() 变数组）
    return $(this).css("color");
}).get();
为什么这么设计「全员统一改」是页面开发 90% 的需求（一队按钮同时变灰、一排卡片同时换色）——广播式设置让你一行顶一个循环；而「读出所有人的值」千姿百态（拼串？成数组？算合计？），库没法替你拍板，所以只给队首、其余自己 each。记住口诀：写广读窄，例外 text。

7.6 军团不是数组：被移除的 push / sort / splice

军团长得像数组，早期 jQuery 干脆把 push、sort、splice 三个数组方法也挂在了原型上——但它们从未写进官方文档，只是内部实现顺手漏出来的。jQuery 4 把这三个「黑户」正式清走了（17 章大扫除清单有它）。这一节顺手把「军团 vs 数组」的边界彻底焊清楚。

文件：not_array.js
// —— jQuery 4 已移除：军团上的数组黑户方法 ——
$lis.push($newLi);                         // ❌ 旧黑户写法：往军团塞人——4.0 报「不是函数」
$lis.sort();                              // ❌ 旧黑户写法：军团排序——同上
$lis.splice(0, 1);                        // ❌ 旧黑户写法：删军团成员——同上

// —— 正确姿势：先转真数组，再用原生全家桶 ——
var arr = $lis.get();                      // 方法 .get()（无参）：军团 → 原生真数组（7.1 学过的还原术）
arr.push($newLi[0]);                       // ✓ 原生 push()：数组尾部塞一个（塞的是原生元素）
arr.sort(function (a, b) {                 // ✓ 原生 sort()：传比较函数
    return $(a).text().localeCompare($(b).text()); // localeCompare：中文也能按拼音序比——按文字给行排序
});
$("ul").empty().append(arr);               // 排好序整队塞回页面（append 也收数组——10 章的入列术）
能力军团（jQuery 对象）真数组（原生 Array）
挑人 / 导航 / 链式全套 jQuery 方法（css / on / find…）❌ 没有
push / sort / splice / filter / map❌ 4.0 起彻底没有原生全家桶
互转通道$军团.get() → 数组；$(数组) / Array.from($军团) → 军团
各自的主场DOM 操作（找元素、改页面）数据加工（排序、去重、聚合）
一句话分界对页面动手用军团，对数据动脑用数组——需要排序、去重、reduce 这类「脑力活」时，先 .get() 变数组干完活，再 $() 变回军团去页面执行。15.3 滚动加载、19.3 购物车都是这条流水线的实战现场。

08

属性与样式：读档与换装的艺术

attr 与 prop 的世纪之辨、data 的隐形口袋、html/text/val 三大读写器、css 与 class 的两套换装术——元素的一切「外貌档案」都在这一章

第 7 章解剖了军团的身子，这一章解决两件事：查档案（这个元素长什么样、存了什么值）和换衣服（把它的外观改掉）。jQuery 给元素准备的档案系统有两套——attr 与 prop，它们长得像双胞胎，却是两个完全不同的世界；换衣服也有两套——css 直接化妆与 class 整套换皮。分清这些「孪生 API」，是从入门走向熟练的分水岭。

8.1 出厂铭牌 vs 实时仪表盘：attr 与 prop 大辨析

HTML 里写的每一个特性（attribute，属性）好比商品的出厂铭牌——出厂时印上什么就是什么，永远不变；而浏览器把标签变成内存里的 DOM 元素后，还有一套实时仪表盘（property，特性）——用户点了勾、代码拨了开关，仪表盘立刻跟着变。jQuery 的 .attr() 读铭牌，.prop() 读仪表盘。

文件：attr_prop_trap.js
// 页面里有一行：<input type="checkbox" id="agree"> —— 出厂时没勾
var $cb = $("#agree");                   // 变量 $cb：勾选框军团

$cb.attr("checked");                     // 方法 .attr()：读铭牌——出厂没写这项 → undefined
$cb.prop("checked");                     // 方法 .prop()：读仪表盘——此刻没勾 → false

$cb.prop("checked", true);               // 写仪表盘：拨到 true——页面上立刻出现对钩
$cb.prop("checked");                     // true：仪表盘已更新
$cb.attr("checked");                     // 仍是 undefined！铭牌纹丝不动——prop 根本不碰 HTML 源码
$cb[0].checked;                          // 原生等价写法：下标取出裸元素直接读（第 7 章「便服」）

// 再看「铭牌说谎」实验——页面里预先写死：<input type="checkbox" id="gift" checked>
$("#gift").prop("checked");              // 用户手动点掉勾之后 → false（仪表盘说了实话）
$("#gift").attr("checked");              // → "checked"（铭牌还在念出厂那页经——它永远不会变）
勾选框之坑（十大新手坑之一）想判断「现在勾没勾」，用 .prop("checked")；用 .attr() 判断是错误答案——铭牌只记得出厂状态。同理想用代码打勾/取消勾，也是 .prop("checked", true/false)。记口诀：状态用 prop，铭牌用 attr。
维度attr()（铭牌）prop()（仪表盘）
存放在哪HTML 源码里（F12 能看到）内存里的 DOM 对象上
会变吗永不——出厂印死的字面值随用户交互、代码操作实时变
返回类型字符串（或 undefined）任意 JS 类型（true / false / 数字…）
典型场景src / href / alt / title / data-*checked / disabled / selected / readOnly

8.2 attr()：读写出厂铭牌

铭牌虽然「不变」，但你可以手动换贴——.attr() 能读、能写、能批量写、能用函数按个换，最后还能整张撕掉。

文件：attr_daily.js
var $img = $("img.banner");              // 变量 $img：所有 class 含 banner 的图片军团

$img.attr("src");                         // 读铭牌：单个特性——图片地址字符串（读窄：只报队首）
$img.attr("alt");                         // 读铭牌：替代文字（图片读不出来时显示的说明）

$img.attr("alt", "新品发布横幅");           // 写铭牌：一个特性一个值——全员换上（写广）
$img.attr({                               // 写铭牌：对象形式——一次批量贴多张
    src: "banner2.jpg",                   // 键 src：换成新图
    alt: "秋季促销横幅",                   // 键 alt：新的替代文字
    title: "点我看详情"                    // 键 title：鼠标悬停时的提示
});

$img.attr("src", function (i, oldVal) {   // 写铭牌：函数形式——i 是成员序号，oldVal 是它的旧值
    return "hd-" + oldVal;                // 返回值成为新铭牌：每张图地址前面都加上 hd- 前缀
});

$img.removeAttr("title");                 // 方法 .removeAttr()：把 title 这张铭牌整张撕掉
为什么读窄写广读铭牌时军团里每个人铭牌可能各不相同，jQuery 没法替你合并，于是只报队首（第 7 章铁律）；写铭牌是广播——一声令下全员统一换。想读所有人的？用 .map() 自己收，第 6 章学过。

8.3 prop()：仪表盘读写与表单三宝

仪表盘世界的主角是表单：checked（勾没勾）、disabled（禁没禁用）、selected（选没选中）——这三位合称「表单状态三宝」，全部用 .prop() 读写。

文件：prop_form.js
var $btn = $("#submitBtn");              // 变量 $btn：提交按钮军团

$btn.prop("disabled");                    // 读仪表盘：此刻禁用了吗（false = 可以点）
$btn.prop("disabled", true);              // 写仪表盘：禁用——按钮立刻变灰、点不动（防重复提交神器）

$("input[type=checkbox]").prop("checked", false); // 广播式写：一键清空所有勾选框（写广——全员统一）

$("#opt1").prop("selected");              // 下拉选项：是否被选中——selected 同为实时状态
$("#msg").prop("readOnly");               // 只读状态——注意铭牌写 readonly，仪表盘的 O 是大写（readOnly）
你要碰的东西用哪个方法典型例子
HTML 里写死的标签特性.attr()src / href / alt / title / data-自定义
随交互变化的实时状态.prop()checked / disabled / selected / readOnly
表单控件的值.val()输入框 / 下拉 / 单选的 value（8.5 节）
隐形数据（不进 HTML）.data()缓存价格、序号、临时标记（8.4 节）

8.4 data()：缝在制服上的隐形口袋

军团成员的每件制服上还缝着一个隐形口袋——.data()。往里塞东西页面上看不见、F12 的 HTML 里也没有，它活在 jQuery 的内存缓存里，读写飞快，还自带「类型自动识别」：塞进去什么类型，掏出来还是什么类型。

文件：data_pocket.js
// HTML 里预先缝好了口袋：<div id="card1" data-price="199" data-tags='["促销","新品"]'></div>
var $card = $("#card1");                  // 变量 $card：卡片军团

$card.data("price");                      // 方法 .data()：读口袋——199（自动把铭牌上的 "199" 转成数字！）
$card.data("tags");                       // ["促销", "新品"]——连 JSON 都自动解析成了数组

$card.data("stock", 42);                  // 写口袋：键 stock、值 42——页面上看不见，也不写进 HTML
$card.data("stock");                      // 42：从口袋里掏出来
$card.attr("data-stock");                 // undefined！铭牌上没有——data 存的是内存，不是 HTML

$card.data({                              // 写口袋：对象形式——一次塞多件
    price: 299,                           // 键 price：覆盖旧值
    stock: 40                             // 键 stock：更新库存
});
$card.removeData("stock");                // 方法 .removeData()：从口袋里扔掉 stock 这一件
$card.data();                             // 不传参数：把整个口袋倒出来看——返回数据对象 {price: 299}
维度attr("data-price")data("price")
存放位置HTML 源码里（F12 看得见）jQuery 内存缓存里（看不见）
返回类型永远是字符串 "199"自动转换：199（数字）/ true / 数组 / 对象
写入之后铭牌真的变了（F12 可验证）只改内存——铭牌原样
读写性能每次都碰 DOM，较慢走缓存，快
口袋一旦装过，就以口袋为准第一次 .data("price") 会把铭牌 data-price 的值抄进口袋缓存；此后哪怕你用 .attr("data-price", 599) 改了铭牌，.data("price") 掏出来的还是旧值。想强制重读铭牌，先 .removeData() 清空口袋。另外，判断口袋里有没有某件东西，用 "price" in $card.data()——jQuery 4 修复了数据对象的原型污染问题，这种写法最稳。

8.5 html() / text() / val()：三大内容读写器

方法读取时写入时一句话比喻
.html()连标签带文字整包读标签会被渲染成真样式整箱快递照单全收
.text()剥掉标签只要文字标签原样显示不当真只留信纸上的字
.val()表单控件当前的值改控件的值表单专用读数器
文件：readers.js
var $box = $("#demo");                   // 变量 $box：演示盒子军团

// —— 读（三者都只报队首——第 7 章「读窄」铁律）
$box.html();                              // 读「整包装修」：如 "<b>你好</b>"——连标签一起抓回来
$box.text();                              // 读「纯文字」：标签全剥掉，只剩 "你好"
$("#name").val();                         // 读「控件值」：输入框此刻的内容

// —— 写（全员生效——「写广」）
$box.html("<b>你好</b>");            // 写装修：<b> 被当成真标签 → 页面显示<b>加粗</b>的「你好」
$box.text("<b>你好</b>");            // 写纯文字：尖括号原样显示 → 页面显示字面的 <b>你好</b>
$("#name").val("小明");                    // 写控件值：输入框里立刻填上「小明」

8.6 css()：单点化妆与 jQuery 4 的 px 新规矩

.css() 是直接往元素脸上化妆的方法：读一个、写一个、批量写一整套、还能按序号逐个化。

文件：css_magic.js
var $tip = $("#tip");                     // 变量 $tip：提示框军团

$tip.css("color");                        // 读：返回「计算后」的值，如 "rgb(7, 105, 173)"（只报队首）
$tip.css("color", "#e8542f");             // 写：一个属性一个值——立即生效
$tip.css("background-color", "#fff7ed");  // 写：属性名可以直接用 CSS 原名的连字符形式

$tip.css({                                // 写：对象形式——一次批量换一整套妆
    "background-color": "#fff7ed",        // 带连字符的键必须加引号
    borderColor: "#fdba74",               // 驼峰写法 borderColor 与上一行等价（不用引号）
    padding: "12px 18px"                  // 简写值也行——上下 12px、左右 18px
});

$tip.css("font-size", function (i, old) { // 写：函数形式——i 序号、old 是它此刻的值
    return parseFloat(old) + 2 + "px";    // 方法 parseFloat()：把 "14px" 剥成数字 14——返回值成为新字号
});

尺寸与位置：量体裁衣与空间定位

盒子模型的前世今生、width 家族四把尺子、offset 与 position 的双坐标体系、scrollTop 滚动刻度——最后合体打出「吸顶导航」实战

想让一个元素「跟着滚动条走」「弹回指定位置」「居中对齐」，都得先会量尺寸和报坐标。jQuery 在这方面准备了一整套「裁缝工具」：量宽有四把尺子（越量越宽）、定位有两套坐标（毛坯图纸与装修房间）、滚动条还有自己的刻度尺。这一章学完，你就能做出招聘信息里最常见的那个需求：吸顶导航。

9.1 盒子模型：每个元素都是一件三层包装的快递

浏览器眼里，每个元素都是一件快递：content 是商品本体、padding 是泡沫防撞层、border 是纸箱本身、margin 是这件快递与邻居之间的摆放距离。量尺寸之前先认清这四层，否则后面四把尺子会把人量糊涂。

文件：box_anatomy.js
var $box = $("#card");                    // 变量 $box：卡片军团

$box.css("padding");                      // 读泡沫层厚度：如 "20px"（四边相同时）；不同时如 "20px 10px"
$box.css("padding-top");                  // 读单边：上泡沫厚度
$box.css("border-width");                 // 读纸箱厚度：如 "2px"
$box.css("border-top-width");             // 读单边纸箱厚度
$box.css("margin");                       // 读箱间距：如 "20px"（transparent 的距离也能读）
box-sizing 的坑CSS 默认 content-box：你设的 width 只是商品本体——加泡沫加纸箱，整件快递实际更胖，布局经常因此「爆宽」。现代页面几乎都先声明 * { box-sizing: border-box; }，让 width 直接等于「整个纸箱宽」。jQuery 尺寸方法读的是实时实际值，两种盒模型下含义随 CSS 走——排错时先查这条。

9.2 width 家族：四把越量越宽的尺子

同一件快递，从里到外有四种「宽」：商品本体宽（.width()）、加泡沫（.innerWidth()）、再加纸箱（.outerWidth()）、连箱间距一起（.outerWidth(true)）——一把比一把量得宽。

文件：size_family.js
var $box = $("#card");                    // 变量 $box：卡片军团

$box.width();                             // 方法 .width()：商品本体宽——纯数字 300（不是 "300px" 字符串！）
$box.innerWidth();                        // 方法 .innerWidth()：本体 + 泡沫（padding）
$box.outerWidth();                        // 方法 .outerWidth()：再 + 纸箱（border）
$box.outerWidth(true);                    // 参数 true：连箱间距（margin）一起量

$box.width(320);                          // 写：直接改本体宽——天生认纯数字（单位它自己搞定）
$box.width("50%");                        // 写：也认百分比字符串
$box.innerWidth(360);                     // 写 innerWidth：按「本体+泡沫」的口径反推本体宽（智能适配）

$(window).width();                        // 特殊军团 $(window)：浏览器视口宽——判断手机/桌面全靠它
$(document).width();                      // 特殊军团 $(document)：整张页面宽（内容超出屏幕的部分也算）
width() 与 css("width") 的区别.width() 返回纯数字（300），可以直接加减乘除；.css("width") 返回字符串（"300px"），做算术前还得剥单位。要计算，用 width() 家族——这是它们存在的意义。

9.4 位置双雄：offset() 与 position()

「这个元素在哪」有两种答案：offset() 报毛坯坐标——相对整张建筑图纸（页面左上角）量；position() 报装修坐标——相对你所在的房间（最近的定位长辈，即 position 不是 static 的祖先；一个都没有时就退化为相对页面）。另外滚动条自己也带刻度：scrollTop() / scrollLeft()。

方法相对谁量返回什么能写吗
.offset()整张页面左上角（图纸原点）{ top: 数字, left: 数字 }能——直接挪到指定页面坐标
.position()最近的定位长辈（房间墙角）{ top: 数字, left: 数字 }只读
.scrollTop()滚动条自己的刻度数字（已滚过的像素）能——滚到指定处
.scrollLeft()横向滚动条刻度数字能

10.2 插入八将：四个落点 × 两种说法

新节点造好了往哪放？落点只有四个：盒子里面最前、里面最后、盒子外面紧前、外面紧后。每个落点又有两种说法——主语是「目的地」（往这塞）或主语是「行李」（塞到那去），共八位大将。

落点目的地版（往这塞）行李版（塞到那去）效果
里面·最后A.append(X)X.appendTo(A)X 成为 A 的末子
里面·最前A.prepend(X)X.prependTo(A)X 成为 A 的长子
外面·紧后A.after(X)X.insertAfter(A)X 成为 A 的弟弟

// 页面结构：<ul id="menu"> <li>苹果</li> <li>香蕉</li> </ul>
var $x = $("<li>新成员</li>");             // 变量 $x：新造的节点（行李）

// —— 目的地版：主语是盒子（目的地）——
$("#menu").append($x);                     // 方法 .append()：塞进 menu 内部最后 → 苹果 香蕉 新成员
$("#menu").prepend($x);                    // 方法 .prepend()：塞进内部最前 → 新成员 苹果 香蕉
$("#menu").after($x);                      // 方法 .after()：贴在 menu 外面紧后（与 ul 平级的兄弟）
$("#menu").before($x);                     // 方法 .before()：贴在 menu 外面紧前

// —— 行李版：主语是新节点（行李）——
$x.appendTo("#menu");                      // 方法 .appendTo()：把 $x 塞到 #menu 尾部（append 的反说法）
$x.prependTo("#menu");                     // 方法 .prependTo()：塞到 #menu 头部（prepend 的反说法）
$x.insertAfter("#menu");                   // 方法 .insertAfter()：贴到 #menu 后面（after 的反说法）
$x.insertBefore("#menu");                  // 方法 .insertBefore()：贴到 #menu 前面（before 的反说法）

$("#menu").append("纯文字也可以");           // append/prepend 还收纯字符串——直接当文本塞进去（免造节点）
链式编程怎么选版本两版返回值不同：.append() 返回目的地军团（后续链操作的是容器），.appendTo() 返回行李军团（后续链操作的是新节点）。想让链继续操作谁，就选以谁为主语的那版——这是八将并存的真正意义。

11.4 事件对象 e：随事件寄来的包裹

处理器第一个参数 e（名字随意，习惯叫 e 或 event）是浏览器随每次触发「寄来的包裹」：里面装着这次事件的全部情报——什么事件、点在哪、按了哪个键、谁喊的话、还能不能拦。

    e.stopPropagation();                   // 方法 .stopPropagation()：拦住冒泡（别再往楼上喊——下一节）

11.5 冒泡：喊声会传遍全楼

点击最里层的 li，它的父级 ul、祖父 div、直到 body 的同款耳朵全部都会响——这叫事件冒泡：孩子的喊声一层层往上汇报，全楼都听得见。顺序永远是「从最深处往外」。

文件：bubble.js
// 页面结构：<div id="outer"> <ul id="menu"> <li id="apple">苹果</li> </ul> </div>
$("#apple").on("click", function (e) {    // 给 li（最深处）装耳朵
    console.log("li 听到了");               // ① 最先响：目标本身
    e.stopPropagation();                   // 拦住上报——楼上（ul / div / body）全听不见（注释掉试试！）
});
$("#menu").on("click", function () {      // 给 ul 装耳朵
    console.log("ul 听到了");               // ② 若没拦冒泡：li 喊完 ul 也响
});
$("#outer").on("click", function () {     // 给 div 装耳朵
    console.log("div 听到了");              // ③ 一路冒泡到 body 为止——每层都会响一次
});
冒泡是 bug 吗不是——是设计。冒泡让「祖先替后代听电话」成为可能：你给 ul 装一个耳朵，就能知道里面任何 li 被点了。这个「设计」的名字叫事件委托，正是下一节。

11.6 事件委托：给祖宗装一台总机

第 10 章动态成绩单里，每造一行就得给删除按钮装一次耳朵——行多了耳朵成灾，而且忘了装就失灵。委托思路反转一下：把耳朵装在不动的祖先（tbody）身上，利用冒泡——谁被点，喊声总会传到 tbody；再用 e.target（或第二参数过滤器）查出「实际喊话人」。

文件：delegate.js（动态成绩单的委托版）
// 旧版（10.5 的写法）：每造一行装一个耳朵——行一多耳朵成灾
// 委托版：tbody 上装一台「总机」，管所有现在和将来的删除按钮
$("#tbody").on("click", ".del", function () { // 委托三件套：不动的祖先 + 事件名 + 委托过滤器 ".del"
    $(this).closest("tr").remove();        // this：实际喊话的 .del（过滤器保证 this 指对了人）
    refreshAvg();                          // 照旧重算平均——函数在 10.5 里定义过
});

    console.log("现在和将来的按钮都能响");     // 动态 append 进来的 .btn 无需再装耳朵！

11.9 on() 的第四种参数：给处理器带行李

委托姿势里其实还藏着一个可选参数——e.data：装耳朵时预存一份数据，触发时随包裹寄到处理器手里。多个相似元素共用一个处理器、又各带各的参数时，它是免闭包的优雅解法。

文件：on_data.js

    console.log(e.data.role);               // e.data.role：取出预存的 "admin"——免闭包也能拿到私货
    console.log(e.data.times);              // e.data.times：预存的 3
});

    $(this).on("click", { idx: i }, function (e) { // 预存各自的序号当行李
        console.log("第", e.data.idx, "个标签被点"); // 触发时取出行李——三个按钮各自报对身份
    });
});

// 完整四参形态（委托 + 数据同时上）：
$("#list").on("click", "li", { mode: "quick" }, function (e) { // 四参全形态：祖先 + 事件 + 委托过滤器 + 数据 + 处理器
    console.log(e.data.mode, e.target.textContent); // 行李与真凶一次到齐
});
on() 参数总谱（背这一张就够了）.on(事件名[, 委托过滤器][, 数据对象], 处理器)——中括号均可省略。数据对象仅在委托形式里可放在过滤器后面；纯绑定形式里它紧跟事件名。e.data 的值装耳朵那一刻就固定（快照），想动态读取请用 8.4 的 .data()。

12.1 键盘事件：keydown、keyup 与 e.key

$("#msg").on("keydown", function (e) {    // keydown：按下瞬间（比 keyup 早——适合「拦截」类逻辑）
    if (e.key === "Enter") {              // 属性 e.key：按键名（字符串）——回车键是 "Enter"
        e.preventDefault();               // 拦默认——表单里回车会触发提交，先拦掉
        sendMsg();                         // 自定义函数：回车即发送（你的业务逻辑）
    }
    if (e.key === "Escape") {             // Esc 键名 "Escape"
        $(this).val("");                  // 清空输入框（取消输入）
    }
});

$("#msg").on("keyup", function () {       // keyup：松开瞬间——适合「输入完成」类统计
    var left = 100 - $(this).val().length; // 变量 left：剩余字数 = 上限 100 减当前字数
    $("#count").text(left);                // 实时显示倒计（val().length：值的字符数）
});

12.7 trigger 的传参与自定义事件：处理器之间打电话

11.7 的 .trigger() 能人工喊话，但它还有个进阶能力——带参数喊话：trigger 的第二参数会原封不动变成处理器的额外参数。配合自定义事件名，不同模块之间就能「打电话」通信——写大型页面和插件（18 章）的地基。

文件：trigger_args.js
// —— 普通事件 + 参数：处理器的第二参数开始收货 ——
$("#btn").on("click", function (e, from, count) { // 处理器参数：e 之后依次接收 trigger 送来的参数
    console.log(from, "喊我来的，已触发", count, "次"); // 参数名随意——from 来源、count 次数
});
$("#btn").trigger("click", ["定时器", 5]); // 方法 .trigger(事件, 数组)：数组逐项变成 from / count
// 注意：用户真实点击时 from / count 是 undefined——只有人工喊话才带货

// —— 自定义事件：模块间的专线电话 ——
$("#cart").on("itemAdded", function (e, item) { // 事件名自造："itemAdded"——购物车模块的专线
    console.log("购物车收到：", item.name);      // 参数 item：货品对象
});
$("#cart").trigger("itemAdded", { name: "马克杯", price: 29.9 }); // 拨号：单一对象会整体变成一个参数

// —— 命名空间 + 自定义事件组合拳（12.6 的进阶用法）——
$("#cart").on("refresh.panel", function () {   // 自定义事件也挂命名空间
    renderCart();                               // 刷新购物车视图（你的渲染函数）
});
$("#cart").trigger("refresh.panel");           // 只拨这条专线的「panel 分机」——别的 refresh 耳朵不响
为什么自定义事件值得学不用它时，模块 A 想通知模块 B 只能直接调对方的函数——两模块从此焊死；用自定义事件，A 只管对着空气喊「itemAdded」，谁关心谁装耳朵——喊话的人不认识听话的人，这就是「解耦」。18.4 的 counter 插件、各大 UI 库的组件通信，内核全是这一招。

显隐、淡入、滑动都是预制动画；.animate() 是自由发挥的万能机：给它一个「目标样式对象」，它就把元素从当前值渐变过去。四件套参数：目标样式 → 时长 → 缓动曲线 → 完成回调。

文件：animate_machine.js
$("#car").animate({                        // 方法 .animate()：参数一「目标样式对象」——想让什么动就写什么
    left: 500,                             // 键 left：横坐标渐到 500px（元素须有 position 定位才能动 left）

          .delay(400)                      // 方法 .delay()：队里插一个 400 毫秒的红绿灯（停一下再演后面的）

13.7 动画队列的原理：queue / dequeue / clearQueue

13.4 说「链式动画自动排队依次演」——那座排队系统叫 fx 队列。队列像一条单通道安检机：每段动画是队伍里的一名乘客，演完一位才放下一位。.queue() 查看队伍、.dequeue() 放行下一位、.clearQueue() 清空还没上机的乘客——stop(true) 清的正是这条队。

文件：queue_lab.js
$("#car").animate({ left: 300 }, 600)      // 乘客 ① 入队：横移
          .delay(400)                      // 乘客 ②：红绿灯（13.4）
          .animate({ top: 200 }, 600);     // 乘客 ③：竖移——三名乘客自动排队

$("#car").queue("fx");                     // 方法 .queue("fx")：查看动画队列——返回函数数组（每名乘客一个函数）
$("#car").queue("fx").length;              // .length：还排着几名乘客（含正在演的）——动画进度仪表

$("#car").queue("fx", function (next) {    // 方法 .queue(队列名, 函数)：往队尾塞一名「自定义乘客」
    $(this).css("background", "#fff7ed");  // 自定义动作：直接换底色（不走动画——瞬时完成）
    next();                                // 关键！调用 next()：放行下一位乘客——忘了写队列就卡死在这
});

$("#car").dequeue("fx");                   // 方法 .dequeue()：手动放行下一位（advance——一般让引擎自动放）
$("#car").clearQueue("fx");                // 方法 .clearQueue()：清空还没演的乘客（正在演的不受影响——等于 stop(true) 的队清部分）

$("#box").queue("steps", function (next) { // 自建队列 "steps"：与 fx 并行的第二条通道（多线动画互不打扰）
    console.log("自定义队列第一步");        // 第二通道的动作
    next();                                // 放行 steps 队的下一位
});
queue(fn) 里 next() 为什么必须调队列是「接力棒」机制：每名乘客演完必须把棒子递给下一位（调 next）；忘了调，后面的乘客全员原地罚站——页面表现为「动画演到一半后再也不动」。这是自定义队列第一大坑，报错还不会提示，只能靠自己记。

AJAX（上）：全参数

跑堂服务员的工作原理、三大快捷方式、$.ajax 全参数解剖、四种发数据的姿势、Promise 风格——跨域与 jQuery 4 的 JSONP 新规矩

到目前为止的数据都是写死在页面里的。AJAX 让 JS 在「页面不刷新」的前提下向服务器要数据、交数据——传统表单提交像顾客亲自跑后厨（整页刷新、体验断裂），AJAX 是跑堂代劳（页面原地不动，局部悄悄更新）。这一章把 jQuery 的整套 AJAX 工具从快捷方式到全参数彻底拆透，下一章全实战。

14.1 AJAX 的工作原理：四步一环

每一场 AJAX 都是同一出四幕剧：发请求（JS 偷偷找服务器）→ 等响应（页面照常可操作，这就是 Asynchronous「异步」）→ 收数据（拿回 JSON 等格式的包裹）→ 更新页面（第 10 章的造节点功夫派上用场）。名字里的 XML 是上古遗风，如今 99% 的包裹都是 JSON。

诚实的旁白：fetch 与 $.ajax现代浏览器原生自带 fetch()，第三方有 axios——都很优秀。但海量存量项目、WordPress 主题插件生态里 $.ajax 依然是日常主食，学会它读老代码零障碍，迁移到 fetch 心智模型完全一致（都是「发请求 → Promise → 拿数据」）。

    contentType: "application/json"       // 声明 MIME：这次发的是 JSON！
});

// 姿势四：FormData——带文件上传（原生构造器）
var fd = new FormData();                  // 变量 fd：原生 FormData() 造一个「表单数据袋」
fd.append("avatar", $file[0].files[0]);  // 方法 .append()：往袋里塞文件（files[0]：选中的第一个文件对象）
$.ajax({
    url: "/upload",                       // 上传地址
    method: "POST",                       // 上传必 POST
    data: fd,                             // 数据袋直接交出去
    processData: false,                   // 关键！别把 FormData 转成查询串
    contentType: false                    // 关键！让浏览器自动配 multipart 边界
});
怎么选姿势普通查询/简单表单 → 对象或 serialize；服务器接口声明 JSON Body → 姿势三；有文件 → FormData（processData 与 contentType 双 false 是口诀）。拿不准看后端文档的 Content-Type 要求，一一对应即可。

14.5 Promise 风格：done / fail / always

success/error 回调是「老式座机」；现代写法把 $.ajax() 返回的 jqXHR 对象当链子用——.done() 成功、.fail() 失败、.always() 收尾，还能接原生同款的 .then()。两种风格都合法，新代码推荐链式。

文件：promise_style.js
$.ajax({ url: "/api/users", dataType: "json" }) // 只留核心参数——结果用链子接
    .done(function (resp) {                // 方法 .done()：成功分支（对应 success）
        console.log(resp);                  // 拿到数据
    })
    .fail(function (xhr, status, err) {    // 方法 .fail()：失败分支（对应 error）
        console.log("出错：", status);       // 提示用户 / 记日志
    })
    .always(function () {                  // 方法 .always()：收尾分支（对应 complete）
        $("#loading").hide();              // 收动画
    });

var jqxhr = $.get("/api/users");          // 变量 jqxhr：$.get 返回的也是 jqXHR——同样可链
jqxhr.then(function (resp) {              // 方法 .then()：原生 Promise 同款接法（还能接第二个失败函数）
    console.log(resp);                     // 拿到数据
});
slim 构建用户注意第 2 章下载对比表提过：jQuery 4 的 slim 构建移除了 Deferred / Callbacks / queue 模块——本节的链式 Promise 风格依赖 Deferred，用 slim 的项目请换完整构建，或改用原生 Promise（官方迁移建议原话）。

14.6 跨域一课：同源策略与 JSONP 的新规矩

浏览器有条家规叫同源策略：协议、域名、端口三者完全一致才算「同源」，AJAX 默认只能问同源的服务器——这是防坏人偷读你登录态的安全墙。跨源要数据，得服务器主动开门：CORS（响应头 Access-Control-Allow-Origin 授权）是现代正道；上古的歪招叫 JSONP（借 script 标签绕道）。

文件：cross_domain.js
// 同源判断示例（页面部署在 https://mysite.com 时）：
"/api/users"                              // 相对路径——永远同源，最安全
"https://mysite.com/api/users"            // 协议+域名+端口全一致——同源 ✓
"https://api.anothersite.com/users"       // 域名不同——跨源！默认被浏览器拦截响应

// 跨源要用 JSONP（老服务器没开 CORS 时的歪招）：
$.ajax({
    url: "https://old.example.com/data",  // 跨源地址
    dataType: "jsonp",                    // jQuery 4 起：必须「显式」声明 jsonp——不再自动提升！
    jsonpCallback: "myCallback"           // 键 jsonpCallback：自定义回调函数名（配合服务器）
});
jQuery 4 变更：JSON 到 JSONP 的自动提升已移除老版本里，url 带 callback=? 这类特征时，即使你没写 dataType: "jsonp"，jQuery 也会「自作聪明」地把它升级成 JSONP 请求——jQuery 4 移除了这个魔法：想发 JSONP，必须显式 dataType: "jsonp"。依赖旧魔法的代码升级后会静默变成普通 JSON 请求然后被同源策略拦截——第 17 章迁移清单的重点项。

14.7 $.ajaxSetup：全站请求的统一制服

全站几十个请求都要带同一个 token、同一个超时、同一个错误处理？逐个写必漏。$.ajaxSetup() 给所有请求发统一制服——之后的每个 $.ajax/$.get/$.post 默认继承这套配置。

文件：ajaxsetup.js
$.ajaxSetup({                             // 方法 $.ajaxSetup()：给后续所有请求设默认参数（统一制服）
    timeout: 8000,                         // 键 timeout：全站默认 8 秒超时
    dataType: "json",                      // 键 dataType：默认按 JSON 解析
    headers: { "X-Token": "abc123" },      // 键 headers：每个请求自动带上鉴权头
    error: function (xhr, status) {        // 键 error：统一失败兜底——漏写 fail 的请求也有底裤
        console.log("全局兜底：", xhr.status, status); // xhr.status：HTTP 状态码（404/500…）
    }
});

$.get("/api/users");                       // 此刻发起的请求自动穿着制服：带 token、8 秒超时、JSON 解析、兜底 error
$.post("/api/save", { a: 1 });             // $.post / $.getJSON 同样继承——一处配置全站生效

$.ajax({ url: "/special", timeout: 2000 }); // 单独请求可「脱掉制服改便装」——就近参数覆盖全局默认

14.8 jqXHR 情报盘：排错四件套

文件：xhr_report.js
$.get("/api/maybe-broken").fail(function (xhr, status, err) { // fail 三参：xhr 报告、status 状态、err 错误对象
    xhr.status;                            // 属性 .status：HTTP 状态码——404 没这接口 / 500 服务器炸了 / 0 请求根本没发出去

    xhr.responseJSON;                      // 属性 .responseJSON：若返回体是 JSON，自动解析好的对象（不是 JSON 则为 undefined）
    console.log(status, err);              // status："timeout"/"error"/"parsererror"；err：具体异常对象
});

// 综合排错模板：把四件套打全，问题基本自曝
$.get("/api/x").fail(function (xhr, status, err) { // 一行流：状态码 + 短语 + 原文前 200 字
    console.log(xhr.status, xhr.statusText, String(xhr.responseText).slice(0, 200));
});

15.2 实战二：搜索联想框（防抖 + 请求竞态）

联想框是工程重灾区：用户连敲 5 个字母，input 事件炸 5 次——真发 5 个请求？防抖说：等用户停手 300 毫秒再发（电梯关门逻辑：有人再进就重新计时）。就算发了，前一个请求还没回来又发新的——竞态会让慢的那个「迟到覆盖」新结果：abort 说：发新的前先掐断旧的。

文件：suggest.js
var timer = null;                            // 变量 timer：防抖计时器句柄（掀桌用的凭证）

    timer = setTimeout(function () {          // 原生 setTimeout：300 毫秒内不再敲键，才真正往下走
        if (lastJqxhr) { lastJqxhr.abort(); } // 方法 .abort()：掐断上一个未归的请求——竞态保险

            renderSuggest(list);              // 渲染联想词（你的渲染函数——结合 10 章造节点）

});

节流（throttle）定时发车固定间隔最多执行一次，动作再密也压着点发滚动监听、mousemove 跟随

15.3 实战三：滚动加载更多（触底判断）

朋友圈式的「上滑自动加载」：窗口滚到距底部 300px 内就拉下一页。三个关键点：触底判断（第 9 章三军团合体）、加载锁（防止触底瞬间连发好几页）、封版标记（服务器说没有了就别再要）。

}, function (xhr) {                        // 第二参数：任意一个失败就走这（短路——不等其余了）
    console.log("有一路失败了：", xhr.status); // 排错定位（14.8 的情报盘）
});

    console.log(val);                       // val：42——同步值原样到达
});

// $.ajax 版本完全体（想给某一路配参数时）
$.when(
    $.ajax({ url: "/api/goods/42", dataType: "json" }), // 每路都可以用完全体自由配置

).then(function (g, s) { renderPage(g[0], s[0]); });
then 参数为什么是数组套数据$.when 诞生于原生 Promise 标准化之前，为了同时携带「数据 + 状态 + 请求对象」三件情报，每路结果包成了数组——所以取真数据要 goods[0]。这是 jQuery 历史包袱之一，记住「when 的 then 里每个参数先 [0] 一下」就不会踩空。
与 slim 构建的关系$.when 依赖 Deferred（slim 构建已移除，14.5 讲过）——用 slim 的项目请改用原生 Promise.all([$.get(…), $.get(…)])：结果数组不带三件套包装，取值更直接（results[0] 直接是数据本体），还能配 async/await——新代码甚至更推荐原生版。

16.8 $.Deferred 完全体：欠条的状态机

16.7 只看了一眼「造欠条 → 兑现」，这里把整台状态机拆开：欠条一生只有三种状态——pending（等待中）、resolved（已兑现）、rejected（已毁约）；兑现/毁约后状态永久锁定，再 resolve 也翻不了案。中途还能无限次「报进度」（progress）。

文件：deferred_full.js
function uploadFile(file) {                // 函数 uploadFile：把「异步上传」包装成欠条工厂（真实场景：FormData + $.ajax）
    var d = $.Deferred();                   // 变量 d：造一张空欠条（pending 状态）
    var pct = 0;                            // 变量 pct：进度百分比
    var timer = setInterval(function () {    // 原生 setInterval：模拟上传进度（每 200ms 走 10%）
        pct += 10;                          // 进度累加
        d.notify(pct);                      // 方法 .notify()：报进度——progress() 的耳朵听见（pending 期间可无限次）
        if (pct >= 100) {                   // 走满
            clearInterval(timer);           // 原生 clearInterval：停掉进度模拟器
            d.resolve("/files/a.png");      // 方法 .resolve(数据)：兑现——done() 的耳朵收到 "/files/a.png"
        }
    }, 200);
    return d.promise();                     // 方法 .promise()：返回「只读视图」——调用方只能听，不能替你 resolve/reject（防外部篡改）
}

        $("#bar").width(pct + "%");         // 进度条实时涨（8.6：百分比字符串也认）
    })

    });

时代站位Deferred 是 jQuery 在原生 Promise 诞生之前自研的异步引擎（2010 年代立功无数）。今天写新代码：异步请用原生 Promise / async-await；jQuery 的 Deferred 读懂即可——海量存量代码（插件、老项目）里它到处都是，14.5 的 jqXHR、15.5 的 $.when、18 章部分插件内部都是它的身影。

// ❌ 旧依赖：切焦点时 focus 与 blur 的非规范交错顺序

插件开发：给军团发新装备

$.fn 原型挂载原理、插件五条军规、可配置的 highlight 插件、带状态与销毁的 counter 插件——从会用到会造的最后一跳

jQuery 能统治前端十几年，秘密武器是插件生态——而插件的原理简单得惊人：往军团原型上挂方法而已。这一章把「造装备」的全套工艺教给你：怎么挂（$.fn）、怎么不污染别人（IIFE 与命名空间）、怎么保持可链（return this）、怎么带配置（$.extend）、怎么管状态与销毁（data + off）。学完你写的不只是插件，是有职业素养的插件。

18.1 原理一览：$.fn 就是军团的军械库

第 7 章说过：所有 jQuery 方法其实都挂在 $.fn（也就是 jQuery.prototype，军团的原型）上。那么——往 $.fn 上挂你自己的函数，等于给全世界军团发新装备。

文件：first_plugin.js
$.fn.greenify = function () {              // $.fn：军团原型（军械库）；键 greenify：装备名
    this.css("color", "green");             // this：调用者军团（本来就是 jQuery 对象！别再包 $(this)）
    return this;                            // 返回军团——保持可链（下一秒讲为什么是铁律）
};

$("p").greenify();                          // 用法：所有 p 全变绿
$("p").greenify().addClass("styled");       // 可链：变完绿接着穿上 styled 皮肤——像原生方法一样自然

18.2 插件五条军规

军规内容违反的下场
① IIFE 包裹 + 严格模式(function ($) { "use strict"; … }(jQuery))全局污染；$ 别名被别人抢走（noConflict 场景）
② 永远 return this结束时把军团还回去链子到你这就断，用户体验-1
③ each 逐成员插件要服务每个成员，不只队首$(“.card”) 三张卡只有第一张生效
④ $.extend 合并配置默认值 + 用户值合并，别逼用户传全参用户必须背下全部参数才敢用
⑤ 命名空间隔离事件挂 .插件名、数据与类名带前缀销毁时误拆别人的耳朵、撞别人的类名

18.3 完整插件：可配置的 highlight

文件：jquery.highlight.js（完整插件，五军规全示范）
(function ($) {                             // 军规①：IIFE 独立作用域，把 jQuery 传进来当 $
    "use strict";                           // 军规①：严格模式——写错更早暴露

    $.fn.highlight = function (options) {   // 挂装备：highlight
        var settings = $.extend({           // 军规④：配置 = 默认值打底……
            color: "#fff7ed",               // 默认底色：暖橙
            text: "",                       // 默认不换文字
            speed: 300                      // 默认动画时长（毫秒）
        }, options);                        // ……用户传什么覆盖什么（16.5 的手艺）

        return this.each(function () {      // 军规②③：返回 this 保链 + each 逐成员
            var $el = $(this);              // each 里 this 是「原生成员」，先穿制服
            $el.stop(true)                  // 先清动画队（13.5 的「先停后演」）
                 .css("transition", "background-color " + settings.speed + "ms") // 借 CSS 过渡做颜色动画（animate 不吃颜色！13.4）
                 .css("background-color", settings.color); // 换底色——注意单位完整（8.6 的 4.0 规矩）
            if (settings.text) {            // 用户传了文字才换
                $el.text(settings.text);    // text() 填充——安全红线（8.5）
            }
        });
    };
}(jQuery));                                 // 把真名 jQuery 递进来——从此插件内部 $ 永远可靠

// —— 用法 ——

18.4 带状态的插件：counter（含销毁）

highlight 是「一次性动作」插件；counter 是「有记忆」插件——用 .data() 当口袋存状态（8.4），用命令字符串（"reset" / "destroy"）当遥控器，销毁时按军规⑤一键清场。

文件：jquery.counter.js
(function ($) {
    "use strict";

    $.fn.counter = function (action) {      // 插件 counter：action 是命令——"reset" / "destroy" / 缺省=初始化
        return this.each(function () {      // 军规②③：保链 + 逐成员
            var $el = $(this);              // 当前成员（穿好制服）

            function render() {              // 内部函数 render：把口袋里的值写到页面
                $el.text($el.data("c-val")); // 从口袋掏当前值显示
            }

            if (action === "destroy") {      // 命令 destroy：销毁——卸妆、拆耳、清口袋
                $el.off(".counter");         // 军规⑤：只拆 .counter 命名空间的耳朵（12.6 一键清场）
                $el.removeData(["c-val", "c-init"]); // removeData(数组)：口袋里指定几件全掏走
                $el.removeAttr("style");     // 卸掉插件化的妆（清行内样式）
                return;                      // 销毁后不再往下走
            }

            if (!$el.data("c-init")) {       // 口袋里没初始化标记 → 第一次见面
                $el.data("c-val", 0);         // 状态从 0 起步，进口袋（8.4）
                $el.data("c-init", true);     // 记上「已初始化」
                $el.css({                    // 顺手化个妆：变成可点的小胶囊
                    cursor: "pointer",       // 手型光标
                    display: "inline-block", // 行内块
                    minWidth: "2em",         // 最小宽度
                    textAlign: "center",     // 文字居中
                    border: "1px solid #cbd5e1", // 描边
                    padding: "6px 10px"      // 内距
                });
                $el.on("click.counter", function () { // 军规⑤：耳朵挂 .counter 命名空间
                    var v = $(this).data("c-val") + 1; // 点一下：口袋值加一
                    $(this).data("c-val", v); // 新值存回口袋
                    $(this).text(v);          // 立刻显示
                });
                render();                    // 首次渲染「0」
            }

            if (action === "reset") {        // 命令 reset：归零
                $el.data("c-val", 0);         // 口袋归零
                render();                     // 重渲染
            }
        });
    };
}(jQuery));

// —— 用法 ——
$("#clicks").counter();                     // 初始化：元素变计数胶囊，点一下加一
$("#clicks").counter("reset");              // 命令：归零
$("#clicks").data("c-val");                 // 读当前值：直接开 data() 口袋（返回数字）
$("#clicks").counter("destroy");            // 销毁：耳朵、口袋、妆容一并清场，元素还原
为什么读值不走插件命令each 内部的 return 不会冒泡到插件外层——命令式插件适合「改状态」（reset/destroy），「读状态」直接开 .data("c-val") 口袋最诚实。想深究命令式 API 的返回值设计，那是进阶话题——先把「口袋存真值」这一招焊牢。

18.6 第三种扩展：$.expr[":"] 自定义选择器

挂方法（$.fn）是给军团发新动作；挂选择器（$.expr[":"]）是给点名系统造新口诀——让你的项目里能写 $(":inview") 这种自造伪类。「批量找符合自定义条件的元素」时，它比 each+filter 更优雅：口诀一次定义，全项目随处点名。

文件：jquery.inview.js（完整自定义选择器）
(function ($) {                             // 军规①：IIFE 独立作用域（18.3 同款骨架）
    "use strict";

    $.expr[":"].inview = function (el) {    // $.expr[":"]：伪类注册表（军械库的另一面墙）；键 inview：新口诀名——$(":inview")
        var $el = $(el);                    // 参数 el：被逐个验身的「原生元素」（引擎会替你遍历候选）——穿制服
        var top = $el.offset().top;         // 元素的毛坯纵坐标（9.4）
        var bottom = top + $el.outerHeight(); // 元素底边 = 顶 + 连边框总高（9.2）
        var viewTop = $(window).scrollTop(); // 视口顶端 = 已滚距离（9.4）
        var viewBottom = viewTop + $(window).height(); // 视口底端 = 顶端 + 视口高（9.3）
        return bottom > viewTop && top < viewBottom; // 判定：元素与视口有交集 → true（经典区间重叠公式）
    };
}(jQuery));

// —— 用法：像原生口诀一样自然 ——
$(".card:inview");                          // 圈出所有「此刻在屏幕里」的卡片——懒加载、滚动动画的标准问法
$(".card:inview").addClass("shown");        // 进屏才穿「入场皮肤」——入场动画的万能起手式

$(window).on("scroll", function () {        // 每次滚动时复查（11.1 的窗口耳朵）
    $(".card:not(.shown):inview").addClass("shown"); // 连招：还没亮过相的 + 此刻在屏内的 → 上场
});
性能军规：自定义伪类没有免费午餐querySelectorAll 帮不了自造口诀——jQuery 只能把前面选中的一切元素逐个送进你的函数验身（5.3 的「jQuery 专属口诀」性能账本）。所以：① 口诀写成 $(".card:inview") 这种先窄后伪的形态（先只圈 200 张卡再验），别裸写 $(":inview")（全页验身）；② 验身函数内别做重活（一次 AJAX、一次大计算都不行）。
插件三件套全景至此你集齐了扩展 jQuery 的三种刀：$.fn 挂动作（18.1–18.4）、$.expr 挂口诀（本节）、$.extend+$ 挂工具（16.5 的命名空间手法）。三种都遵循同一条朴素哲学：往军械库的公共墙上，挂一件带你自己名字牌的装备——这就是 jQuery 生态繁荣了二十年的全部秘密。

    if (xhr.status === 0) {                  // 状态码 0：请求压根没出门（14.8 的表）
        lines.push("多半是：断网 / 跨域被拦 / 地址协议不对"); // 三大惯犯直接点名
    }
    console.warn(lines.join("\n"));          // 原生 join：拼成一段——控制台黄字醒目提示（区别于业务日志）
});
排错动线先贴上面这段 → 复现故障 → 读黄字四行 → 对照 20.1 病症 9 与 14.8 状态码表 → 修复。控制台 + Network 面板 + 这段钩子 = AJAX 排错三件套；「黄字都不出」说明请求压根没发出（代码没跑到 / 选择器空军团——回病症 1 先做 length 体检）。
